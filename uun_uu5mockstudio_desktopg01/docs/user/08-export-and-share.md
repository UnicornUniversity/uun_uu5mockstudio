# 8. Export and share

## Export (save a file)

From the bar over a selected screen (**Export ▾**) or the **File → Export** menu:

| Entry | Result |
| --- | --- |
| **Image…** | the screen as PNG, JPEG or PDF, at the size of its frame |
| **Save a copy of the HTML…** | the HTML file of the screen |
| **Save the whole project (ZIP)…** | every screen of the project in one ZIP (also **File → Project as ZIP…**) |

## Share (send it to someone)

**Share ▾** on the bar (or **File → Share**):

| Entry | Result |
| --- | --- |
| **Share image…**, **Share HTML file…**, **Share the whole project (ZIP)…** | on macOS the system share sheet opens (Messages, Mail, AirDrop, WhatsApp, Signal …); elsewhere an e-mail draft with the file attached |
| **⠿ Drag the image into an app**, **⠿ Drag the HTML file into an app** | press and hold the entry and drag it into a chat, a mail or a folder; the file is prepared when the menu opens (a moment of "preparing…") |

An exported HTML file needs the Plus4U CDN to render, like the screens in the app.
