# 10. Keyboard shortcuts and menus

## Shortcuts

| Shortcut | Does |
| --- | --- |
| ⌘N | New project |
| ⌘O | Switch project |
| ⇧⌘W | Close project (back to the dashboard) |
| ⇧⌘D | Dashboard |
| ⌥⌘D | Project description |
| ⌥⌘R | Business rules |
| ⌘Enter (also ⇧⌘F) | Present the selected screen (also leaves it); Esc leaves too |
| ⌥⌘N | Add a note to the selected screen |
| ⇧⌘N | New chat |
| ⇧⌘L | Floating / docked chat |
| ⌘Z, ⇧⌘Z | Undo, redo: the typing in a text field, otherwise the last change of the screen |
| ⌥⌘Z, ⇧⌥⌘Z | Undo, redo of a change of the screen (menu Screen) |
| ⌘= , ⌘− | Zoom in, zoom out |
| ⌘0 | Show all screens |
| I | Turn the inspector on or off |
| Esc | Close the top dialog, leave the inspector or picking |
| Delete | Delete the selected screen (asks first) |
| Enter, Shift+Enter | Send, new line in the message field |
| ⌘ + scroll, pinch | Zoom the canvas |
| ⌥ + scroll | Move the canvas while the pointer is over a screen |
| Shift / ⌘ / Ctrl + click | Add or remove a component in a pick (inspector, chat) |

## Menus

- **File**: New Project…, Switch Project…, Close Project, **Export** (screen as image, as HTML, project as ZIP), **Share** (screen image, HTML file, project ZIP), Quit.
- **Project**: Rename Project…, Project Description…, Business Rules…, **Git Repository** (link, Switch Branch…, Open Repository Folder, Unlink Repository), **Projects Folder** (show, Change…), Delete Project….
- **Screen** (acts on the selected screen): Present, Reload Screen, Add Note, Description…, **Show Component Tree…**, Undo / Redo Screen Change, Add Rule…, Mention in Chat, Show in Finder, Delete Screen…. The same entries are in the context menu (right click) of a screen.
- **Chat**: New Chat, Chat History…, Floating / Docked Chat.
- **Edit**: Undo, Redo (typing or the last change of the screen), Cut, Copy, Paste, Select All.
- **View**: Zoom In / Out, Show All Screens, Arrange Screens, Device for All Screens, Element Inspector, **Appearance** (theme, Glass Effect), **Offline Use**.
- **Help**: Welcome Tour…, Claude Code & Plugins…, Check for Plugin Updates…, Check for Updates….
