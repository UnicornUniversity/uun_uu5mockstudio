# 10. Keyboard shortcuts and menus

## Shortcuts

| Shortcut | Does |
| --- | --- |
| ⌘N | New project |
| ⌘O | Switch project |
| ⇧⌘W | Close project (back to the dashboard) |
| ⇧⌘D | Dashboard |
| ⌥⌘D | Project description |
| ⌥⌘R | Business rules |
| ⌘Enter (also ⇧⌘F) | Present the selected screen (also leaves it); Esc leaves too |
| ⌥⌘N | Add a note to the selected screen |
| ⇧⌘N | New chat |
| ⇧⌘L | Floating / docked chat |
| ⌘Z, ⇧⌘Z | Undo, redo: the typing in a text field, otherwise the last change of the screen |
| ⌘= , ⌘− | Zoom in, zoom out |
| ⌘0 | Show all screens |
| I | Turn the inspector on or off |
| ⇧⌘/ (⌘?) | Open the user guide |
| Esc | Close the top dialog, leave the inspector or picking |
| Delete | Delete the selected screen (asks first) |
| ⌘C / ⌘V | Copy the selected screen, paste it on the canvas (also in another project) |
| Enter, Shift+Enter | Send, new line in the message field |
| ⌘ + scroll, pinch | Zoom the canvas |
| ⌥ + scroll | Move the canvas while the pointer is over a screen |
| Shift / ⌘ / Ctrl + click | Add or remove a component in a pick (inspector, chat) |

## Menus

- **File**: New Project…, Switch Project…, Close Project, **Export** (screen as image, as HTML, as uu5String, project as ZIP), **Share** (screen image, HTML file, uu5String, project ZIP), Quit.
- **Project**: Rename Project…, Project Description…, Business Rules…, **Git Repository** (Link / Change Repository…, Switch Branch…, Open Repository Folder, **Start from an Existing Component…**, **Hand Off for Production…**, Unlink Repository), **Projects Folder** (show, Change…), Delete Project….
- **Screen** (acts on the selected screen): Present, Reload Screen, Add Note, Description…, Variants…, **Use This Variant…** (only when the screen is a variant or has variants), **Show Component Tree…**, Save as Template…, Add Rule…, Mention in Chat, **Copy Screen**, **Paste Screen**, **Copy to Project**, Show in Finder, Delete Screen…. A change of the screen is undone with the standard **Edit → Undo / Redo** (⌘Z, ⇧⌘Z) outside a text field. The context menu of a screen (right click, or ⋯ in its bar) keeps the everyday actions at the top – Add note, Edit components, Mention in chat, Present, Fit screen, Reload screen – and puts the rest into three submenus: **Screen** (Description…, Device size…, the choice of a variant, Variants…, Add rule…, Check against brand guide), **Code** (Show component tree, **Update from code…** on a screen made from an existing component, **Hand off this screen…** with a linked repository) and **File** (Copy screen, Copy to project…, Show in Finder); Delete screen… is last.
- **Chat**: New Chat, Chat History…, Floating / Docked Chat.
- **Edit**: Undo, Redo (typing or the last change of the screen), Cut, Copy, Paste, Select All.
- **View**: Zoom In / Out, Show All Screens, Arrange Screens, Device for All Screens, Edit Components, Show / Hide Screen Flow.
- **Settings…** (⌘, on macOS in the app menu; **File → Settings…** on Windows and Linux): everything that is set up once, see [Settings](09-appearance-and-settings.md#settings): your role, the projects folder, the theme and Glass effect, Claude Code and Codex, the uuAiChat MCP server, picture generation, offline use.
- **Help**: **User Guide…** (⇧⌘/), Welcome Tour…, Check for Updates….
