## uu5Mock Studio 0.21.0

### New
- **Sitemap from a link.** A sitemap can start from pages that exist. Give the address of a web site, of a uuBookKit book or of a uuManagementKit document / portal: the app reads the structure of its pages (the menu of the book; the pages, the navigation and the links of the document; the menu, the links and the `sitemap.xml` of the site) and you pick all or some of them. **Load its pages** on a row goes one level deeper where you need it.
- **Two ways to use the picked pages:** **Use as the sitemap** makes them the sitemap of the project as they are; **Hand to the agent** attaches them to your next message in Plan mode, so the agent proposes the sitemap from them.
- **Where to find it:** **From a link…** among the ways to make a sitemap (the Sitemap button, the Plans menu), and the card of a pasted link, in the chat and on the dashboard when **Whole web site** / **Portal** is chosen.
- **Reference or Sitemap.** The card of a pasted link says what the link is for: **Reference** (the page as the input of a design, as before) or **Sitemap** (the structure of the pages behind it as the input of the sitemap). **Choose the pages…** on the card opens the picker.
- **Load with my access…** in the picker: sign in to a web site in a window of the app, and its structure is read as you see it.
- **A page remembers where it comes from.** The page editor of the sitemap has a **Source** field. When you create the screen of such a page, the app reads the page first and the agent builds the screen from its content.
- **Pictures from more places.** The agent now finds the pictures of web pages that a script draws and of pages you signed in to in the app, and downloads them with that sign-in. The pictures of a uuBookKit page are downloaded with the page, and the agent can copy the pictures of a Plus4U document into the design. Pictures that load only as you scroll are found too, and a picture a page keeps only in memory is saved by the app.

### Changed
- A web page that sends you on to another address by script is read instead of being reported as a file to download.

### Requirements
- Claude Code (the app offers to install it) and a Claude account, **or** Codex (the Codex CLI or the ChatGPT app) signed in.
- The plugins come from the uuCodebase marketplace over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.
- Plus4U documents need the `uubookkit` / `uumanagementkit` plugins of the uuAiMarketplace, Node.js (`npx`) and a Plus4U sign-in.

### Downloads
- `uu5Mock-Studio-0.21.0-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.21.0-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.
