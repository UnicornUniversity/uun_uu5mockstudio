## uu5Mock Studio 0.35.0

### New
- **Hand off for production** (Solution architect, Advanced view): the top bar, the Project menu or a screen's menu (**Hand off this screen…**) makes a branch `feature/<name>` in the linked repository with the handoff package – the specification (HANDOFF.md), the task for the agent (BUILD.md, PROMPT.md), the mockups and pictures of the screens. Your checkout is not touched. The branch starts from a local or a remote branch you choose (**Fetch** brings the remote ones up to date; a local branch behind its remote is pointed out). Helpers that only belong to the mockup (demo switches, fake data, the page shell) are left out.
- **After the handoff the dialog says what to do next**: work on the branch **in your working copy** (it is switched to the branch when it has no uncommitted changes) or **in a separate folder** next to it; then open it in VS Code, in the Claude app or in a terminal and send the task. The task says in plain words which files change and how, which components are created, what is removed and what stays – the same text for Claude Code and Codex.
- **Start from an existing component** (dashboard, Project menu): pick a component file of the repository and either extend / redesign it or design a new component modelled on it. The app reads the component and the files it imports – render props, early returns, higher-order components, providers, loaders and hooks of the libraries – and the agent builds a mockup screen to work on. A screenshot of the real application can be attached.
- **Redesigns are handed over against the original**: each component is Modify, Keep or Remove, new ones are Create; mockup components can be linked to files of the repository (a file picker of the repository).
- **Plan limits in the chat**: a ring in the footer of the chat shows how much of the Claude or Codex plan is used; a click shows the detail.

### Changed
- **Component tree**: for a screen made from an existing component, **Real structure** shows the component as it is in the code (library components such as ContentContainer stay as they are) with the new parts in their place; **Only changes** hides everything else; **Re-read the code** reads it again.
- **Claude with a subscription ignores a system `ANTHROPIC_API_KEY`** (Settings let you choose the API key instead), so the plan limits work in an installed app too.
- The dashboard chat accepts attachments (screenshots); Plan mode shows "Preparing the plan…" on the empty canvas.

### Requirements
- Claude Code (the app offers to install it) and a Claude account, **or** Codex (the Codex CLI or the ChatGPT app) signed in.
- Picture generation additionally needs an OpenAI API key (optional).
- The plugins come from the uuCodebase marketplaces over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.
- Plus4U documents need the `uubookkit` / `uumanagementkit` plugins (the app installs them), Node.js (`npx`) and a Plus4U sign-in.

### Downloads
- `uu5Mock-Studio-0.35.0-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.35.0-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.
