## uu5Mock Studio 0.2.0

### What's new
- **Menus by topic.** *File* keeps the life cycle of a project, export and share; new *Project* (description, business rules, git repository, location, delete), *Screen* (fullscreen, reload, note, description, rule, mention, delete) and *Chat* menus. The same screen actions are in the ⋯ menu of a screen.
- **Inspector: mark several components.** Shift / Cmd / Ctrl + click marks more components (orange frames), *Use N in chat* adds them all to the message at once.
- **Icons everywhere.** Every prop with *icon* in its name (`typeIcon`, `rightIcon`, `iconRight` ...) gets the icon palette; `stateIcon` gets a palette of uuBml states (state number + kind, read from the uuBml icon font). The icon dialog has a second library, the **uuBml icons** (874), and always shows the current value first.
- **Glass Effect (macOS).** *View → Appearance → Glass Effect*: translucent, blurred panels (floating chat, toolbar, menus, dialogs, inspector), light and dark; off with macOS *Reduce transparency*.
- **The agent sees more.** It looks at a screenshot of a screen before changing it and can open dialogs, forms and tabs with the new `browser_click` tool.
- **Screens.** *Reload screen* in the screen menu; the chat dock button works in the fullscreen preview too (the chat docks on the left, the preview starts to its right).
- **Chat header** polished: one dock/float icon, icons of one size, a clearer new-chat icon.
- **Open source.** The repository now has a README, a LICENSE (GPL v3 with an additional permission for the Claude Agent SDK) and a script that publishes a release to GitHub.

### Requirements
- Claude Code (the app offers to install it) and a Claude account.
- The plugins come from the uuCodebase marketplace over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.

### Downloads
- `uu5Mock-Studio-0.2.0-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.2.0-arm64.zip` – the same app as a zip.

The builds are **not code-signed**: on macOS open the app with right click > Open the first time.
