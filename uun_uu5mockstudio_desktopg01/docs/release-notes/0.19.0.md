## uu5Mock Studio 0.19.0

### New
- **The sitemap is an item of the project.** An approved map becomes the **sitemap of the project**: a file of its own (`sitemap.json`) and a **Sitemap** card on the canvas, edited like the map in a plan and saved at once. The map in a plan is now a proposal: **Approve the map** saves it as the sitemap of the project (a map it replaces is kept, **Undo** takes it back) and the plan keeps its text and a note.
- **Revise with the agent** on the Sitemap card asks for a revised map in Plan mode; it comes back as a plan to review and approve, so the map of the project never changes behind your back.
- **The agent knows the map of the project** (structure, names, which pages have a screen), keeps to it when it builds a screen, never edits the file and builds only the pages you ask for.
- **Two buttons in the toolbar.** **Sitemap** goes to the sitemap card (also when it was hidden) or hides it, and without a sitemap offers **From the screens**, **Empty map** and **Ask the agent…**. **Plans** lists the plans of the project: **Show** brings a hidden card back and goes to it, **Hide** takes it off the canvas.

### Changed
- **Cards no longer lie on each other.** A new card gets a free place, a hidden card that is shown again moves if its old place was taken, an older layout with overlapping cards is put right when the project is opened, and **Arrange the cards** in the Plans menu tidies all of them. "No mockup yet" is not shown while cards are on the canvas.
- **Plans in the Plans menu** with the same title are told apart (by date), a generic "Plan" title is replaced by the first heading of the plan, and a plan can be **deleted** there (to the trash). A plan that cannot be drawn shows why instead of an empty card, and does not stop the other cards from appearing.
- **A finished plan leaves the canvas.** Once a plan is approved, built or discarded, its card goes off the canvas (the Plans button brings it back), so showing the sitemap no longer shows the old plan with it. The title of a revised plan follows its text (no more plans that are all called "Plan").
- **From an existing plan to a sitemap:** **Make a sitemap from this plan** (also for a plan that only has a component tree) and **Use as the sitemap of the project** on a plan whose map was already approved.
- **Generate from the screens** moved from the plan card to the Sitemap button: it makes the sitemap of the project.

### Requirements
- Claude Code (the app offers to install it) and a Claude account, **or** Codex (the Codex CLI or the ChatGPT app) signed in.
- The plugins come from the uuCodebase marketplace over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.
- Plus4U documents need the `uubookkit` / `uumanagementkit` plugins of the uuAiMarketplace, Node.js (`npx`) and a Plus4U sign-in.

### Downloads
- `uu5Mock-Studio-0.19.0-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.19.0-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.
