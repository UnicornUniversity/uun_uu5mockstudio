## uu5Mock Studio 0.21.2

### Changed
- **Open full plan.** The plan card in the chat shows the beginning of the plan, faded out, and a button **Open full plan** that opens the whole plan in the large view (so does a click on the text). It replaces **Show on canvas** and the note that pointed to the canvas card. **Sitemap** next to it opens the sitemap of the project once the map has been approved.
- **The exported sitemap has a legend.** The picture of the sitemap (**Export** → PNG, SVG or copy) explains under the map what its boxes mean: a page with or without its screen, a section, a group, a link out of the site, a page not solved here, a folded branch. Only the kinds the map uses are listed.

### Requirements
- Claude Code (the app offers to install it) and a Claude account, **or** Codex (the Codex CLI or the ChatGPT app) signed in.
- The plugins come from the uuCodebase marketplace over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.
- Plus4U documents need the `uubookkit` / `uumanagementkit` plugins of the uuAiMarketplace, Node.js (`npx`) and a Plus4U sign-in.

### Downloads
- `uu5Mock-Studio-0.21.2-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.21.2-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.
