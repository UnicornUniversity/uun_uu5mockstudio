## uu5Mock Studio 0.22.0

### Added
- **A map of a web site or of portals.** The switch **Web | Portals** in the header of the sitemap says what the map is. A web site (also a book of uuBookKit) is made of pages and their sections; portals (documents of uuManagementKit) are made of **portals → sheets → sections**. The new type **Sheet** is a sheet of the portal above it with a screen of its own. In a map of portals each node shows its type as a small chip, the menus and the editor use the names of portals, and adding inside a portal adds a sheet, inside a sheet a section. The header counts them (for example *3 portals, 18 sheets, 9 sections*) and the exported picture explains them in its legend. A map read from a document of uuManagementKit starts as a map of portals, its own pages as sheets; a Document project starts an empty map the same way.
- **Zoom the sitemap.** ⌘ / Ctrl + scroll or a pinch zooms the map around the pointer. In the full view of the map the zoom pill of the top bar (with **Fit the map**) and ⌘ + / − / 0 zoom the map, not the hidden canvas.

### Requirements
- Claude Code (the app offers to install it) and a Claude account, **or** Codex (the Codex CLI or the ChatGPT app) signed in.
- The plugins come from the uuCodebase marketplace over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.
- Plus4U documents need the `uubookkit` / `uumanagementkit` plugins of the uuAiMarketplace, Node.js (`npx`) and a Plus4U sign-in.

### Downloads
- `uu5Mock-Studio-0.22.0-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.22.0-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.
