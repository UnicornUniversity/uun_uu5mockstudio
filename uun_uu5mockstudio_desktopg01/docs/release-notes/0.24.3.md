## uu5Mock Studio 0.24.3

### Added
- **Approved pages in the sitemap.** A page you have reviewed can be marked as approved: a check on the right of the node (a click switches it), the **Approved** box in the page settings, the right-click menu, and a bulk setting for several selected pages. The header shows `X / Y approved` and a **Dim approved** switch fades the approved pages so the ones still to review stand out.
- **An approved page that has a screen asks before it is changed:** renaming, moving, retyping or deleting it needs a confirmation.
- **The agent keeps approved pages as they are** when it revises the map (title, place, type and screen file).
- **The uu5string export of the sitemap** marks an approved page with an `APPROVED` badge.

### Requirements
- Claude Code (the app offers to install it) and a Claude account, **or** Codex (the Codex CLI or the ChatGPT app) signed in.
- Picture generation additionally needs an OpenAI API key (optional).
- The plugins come from the uuCodebase marketplace over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.
- Plus4U documents need the `uubookkit` / `uumanagementkit` plugins of the uuAiMarketplace, Node.js (`npx`) and a Plus4U sign-in.

### Downloads
- `uu5Mock-Studio-0.24.3-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.24.3-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.
