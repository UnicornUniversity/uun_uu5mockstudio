## uu5Mock Studio 0.6.1

### What's new
- **Preview of a component in the Components tab**: the detail of a component of Uu5Elements or Uu5Forms shows it rendered live above its props (drag the lower edge to make it taller). Components that show nothing on their own (modals, buses, providers, hooks, the parts of a bigger component) have no preview.
- **Better ready-made code**: a list with no items showed nothing, so a required `itemList` now gets two sample items, a form field gets a label and a block a header; about 25 more components (Alert, Breadcrumbs, ButtonGroup, Carousel, Grid, InfoGroup, Pagination, ScrollableBox, SideDetailLayout, FormRadios …) have hand-written code. This is the code that is dropped onto a screen as well.
- **Picked components in a message**: the text holds a short link `[#1]` and the chip above the field names the component. **Click a chip** to see it: its screen comes into view and the component is framed for a moment.

If you run 0.3.0 or newer, **Download** in the update strip installs this version and restarts the app by itself.

### Requirements
- Claude Code (the app offers to install it) and a Claude account.
- The plugins come from the uuCodebase marketplace over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.

### Downloads
- `uu5Mock-Studio-0.6.1-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.6.1-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.
