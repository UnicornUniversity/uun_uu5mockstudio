## uu5Mock Studio 0.24.4

### Fixed
- **The Agent / Plan menu is readable again:** the selected item no longer gets the solid blue background with a grey description and a blue check on it.
- **Revising the sitemap from its card no longer switches the chat to Plan.** That one request is still planned, but the Agent / Plan switch stays as you set it, so your next message in the chat changes the screens as you asked.
- **A pasted link reads its structure only once.** The pages the card read for **Sitemap** are shown at once in **Choose the pages…** (Reload still reads them again).

### Requirements
- Claude Code (the app offers to install it) and a Claude account, **or** Codex (the Codex CLI or the ChatGPT app) signed in.
- Picture generation additionally needs an OpenAI API key (optional).
- The plugins come from the uuCodebase marketplace over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.
- Plus4U documents need the `uubookkit` / `uumanagementkit` plugins of the uuAiMarketplace, Node.js (`npx`) and a Plus4U sign-in.

### Downloads
- `uu5Mock-Studio-0.24.4-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.24.4-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.
