## uu5Mock Studio 0.8.4

### What's new
- **One copy of a repeated component**: a tile the screen renders for each item of a list (`CONTACTS.map(…)`) can now be picked on its own. **⌘ / Ctrl + click** in the Edit mode marks just the copy you clicked, each with its own frame; click more to add them. The chip in the chat names the item, e.g. `CONTACTS[0] (name: "Jan Novák")`, and the agent changes only those items. A click or Shift + click still marks the component with all its copies (the others get a dashed frame).
- **Plus4U documents as input**: paste a link to a uuBookKit page or a uuManagementKit document into the message. The app reads the document (read only, through the uuBookKit / uuManagementKit plugins), shows it as a card with a preview and gives it to the agent with the message. The territory (USO, USY, SWF or your own) is chosen once.
- Switching on the Edit mode keeps the chat open: the side panel no longer jumps to the Components catalog.

If you run 0.3.0 or newer, **Download** in the update strip installs this version and restarts the app by itself.

### Requirements
- Claude Code (the app offers to install it) and a Claude account, **or** Codex (the Codex CLI or the ChatGPT app) signed in.
- The plugins come from the uuCodebase marketplace over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.
- Plus4U documents need the `uubookkit` / `uumanagementkit` plugins of the uuAiMarketplace, Node.js (`npx`) and a Plus4U sign-in.

### Downloads
- `uu5Mock-Studio-0.8.4-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.8.4-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.
