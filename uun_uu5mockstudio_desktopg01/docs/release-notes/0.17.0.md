## uu5Mock Studio 0.17.0

### New
- **Sitemap in Plan mode.** For a portal, a web site or any request about several pages, the agent starts with a **map of the pages**. The plan card shows it as a tree (root on the left, pages to the right): pages, groups that only gather pages in the menu, and external links. **✔** marks a page whose screen exists, **○** one that does not yet.
- **Edit the map right on the card**: rename a page, change its type, screen file and note, add a page inside or after, move it up, down, in or out, delete it. Every change is written to the plan file at once.
- **Create the screen** on a page has the agent build just that page, in its place in the map; **Open the screen** jumps to an existing one. **Approve & build** builds one screen per page with a navigation that follows the tree, and takes your edits of the map into account.

### Changed
- A selected page of the map can be **deselected**: click it again, click the empty map, or press **Deselect**.
- **Select several pages of the map** (Shift / ⌘ / Ctrl + click) to give them one comment, or one type, together.
- **A long map is usable**: it scrolls by itself, the editor of the selected page stays at the bottom of the card, and the map keeps its place when you select a page.
- **Review the map with the agent.** Write a comment on any page of the map (it gets an orange mark) and/or a wish about the whole map, then **Revise with the agent**: the agent resolves the comments and returns the revised map in the same plan.
- **Sections.** A node of the map can be a **section**: a chapter, block or tab inside a page, with no screen of its own. Sections are drawn small and dotted and are not counted as pages (Map (12 pages, 30 sections)); the agent is told to use them for what a page contains instead of making every item a page.
- **The sitemap is asked for more firmly.** The planning prompt says that a map of pages or portals is a sitemap block of the plan, not a screen with a map and not a component tree, and that the component tree is only for a plan that builds one screen. A revised plan comes back whole, the sitemap included.
- A plan card without a sitemap has **Add a sitemap** (the agent adds it to this plan), and the component tree on a card can be removed (**Remove the tree**).
- **The component tree on the plan card on the canvas** is the same as in the chat: a diagram or an outline (switch), the description of a library component on click, **Hide / Show the component tree**, and boxes can be dragged (a move is written into the plan file).
- A plan with a sitemap opens its card larger; the chat card shows the number of pages.

### Fixed
- Selecting a page at the bottom of a long map no longer hides it behind the editor: the map moves so that the selected page stays in sight.
- Over a plan card on the canvas, **Alt / Option + scroll** moves the canvas, like over a screen.
- **The large view of the component tree** no longer puts its Diagram / Outline switch under the window buttons of macOS.

### Requirements
- Claude Code (the app offers to install it) and a Claude account, **or** Codex (the Codex CLI or the ChatGPT app) signed in.
- The plugins come from the uuCodebase marketplace over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.
- Plus4U documents need the `uubookkit` / `uumanagementkit` plugins of the uuAiMarketplace, Node.js (`npx`) and a Plus4U sign-in.

### Downloads
- `uu5Mock-Studio-0.17.0-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.17.0-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.
