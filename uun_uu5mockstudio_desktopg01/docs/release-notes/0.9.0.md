## uu5Mock Studio 0.9.0

### What's new
- **Page templates for documents**: a new level **Page** on the dashboard with six templates made of uu5Bricks: **Portal**, **Landing page**, **Home page**, **Product detail**, **Article** and **Report**. A Page is meant to be copied with **Copy as uu5String** into a uuBookKit page or a uuManagementKit portal; the agent builds it only from Bricks and from nothing the uu5String would lose.
- **uu5Bricks in the component catalog**: Uu5Bricks, Uu5ChartsBricks, Uu5ImagingBricks, Uu5TilesBricks and the other Bricks libraries are in the library browser, the `@` suggestions and the checks of plans, read from the `uu5bricks` plugin (now a recommended plugin). The common Bricks can be dropped onto a screen.
- **Your own templates**: the new **Save as template** button in the toolbar of a screen (also **Screen → Save as Template…**) turns a screen, or several screens of a project, into a template of your own: a title, the level, a description, the sentence for the message field and instructions for the agent; the business rules of the project and the notes of the screens can go with it. In **Templates…** your templates have **Edit…**, **Show in Finder**, **Export ZIP…** (to pass on to a colleague) and **Delete**.
- **A template is a starting point, not a screen**: a project started from a template no longer shows the template's sample screen; the agent builds what you asked for from the example (a Product detail template asked for a course page gives `course-detail.html` only).

### Fixes
- **Image export of a long page**: a screen taller than its frame was exported with its first part repeated all the way down. The whole page is now in the picture (PNG and JPEG).

If you run 0.3.0 or newer, **Download** in the update strip installs this version and restarts the app by itself.

### Requirements
- Claude Code (the app offers to install it) and a Claude account, **or** Codex (the Codex CLI or the ChatGPT app) signed in.
- The plugins come from the uuCodebase marketplace over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.
- Plus4U documents need the `uubookkit` / `uumanagementkit` plugins of the uuAiMarketplace, Node.js (`npx`) and a Plus4U sign-in.

### Downloads
- `uu5Mock-Studio-0.9.0-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.9.0-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.
