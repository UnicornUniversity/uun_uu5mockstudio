## uu5Mock Studio 0.8.0

### What's new
- **A screen as uu5String**, ready to paste into a document (uuBookKit, uuManagementKit). It is taken from the screen as it is rendered now: lists are expanded, texts computed, components defined in the screen leave what they render, components of uu5 libraries keep the props you set (defaults are left out) and the CSS classes of the screen are written as inline styles.
- **Only a part of the screen**: in the Edit mode click a component (Shift-click marks more, also in other screens) and press **Copy as uu5String** in the Edit panel. A component inside a list gives every item of the list.
- **What could not go in is reported**: after copying, **Details** lists left-out event handlers, closed dialogs (open one and copy again to include it) and CSS that cannot be inline (`:hover`). Spaces next to tags are kept (`&nbsp;`), so a document does not glue the words together.
- **A new Share menu**: the bar over a screen has one **Share** button instead of two icons. First pick what goes out (**Image**, **HTML file**, **uu5String**, **Project ZIP**), then what to do with it: **Copy**, **Save…**, **Share…** or **Drag** into a chat, a mail or a folder. The menu remembers the last pick.
- **Copy works for every format**: the image as a picture, the HTML as its source, the uu5String as text and the project ZIP as a file (paste it into Finder, Mail or a chat).
- **Fix: the Share menu and the ⋯ menu no longer overlap**; opening one closes the other.

If you run 0.3.0 or newer, **Download** in the update strip installs this version and restarts the app by itself.

### Requirements
- Claude Code (the app offers to install it) and a Claude account, **or** Codex (the Codex CLI or the ChatGPT app) signed in.
- The plugins come from the uuCodebase marketplace over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.

### Downloads
- `uu5Mock-Studio-0.8.0-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.8.0-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.
