## uu5Mock Studio 0.10.0

### New
- **Frames from a link**: paste the link of a real page (uuManagementKit, uuBookKit, any web page) and make a frame of it. Screen title bar → **Shown in** → **New frame from a link…**. A window opens with the page (the Plus4U sign-in is kept there): sign in, open the page, then choose the area where the content of a page goes (click an element, widen or narrow it with the wheel, **▲ Larger** / **▼ Smaller** and **✓ Use this**, or drag a rectangle). Everything around that area becomes the frame: top bar, menu, route header, buttons, icons and background pictures, taken from the real page. Claude can then tidy the frame up (the title and the breadcrumb become variables for every screen) without changing how it looks.
- **Frames are yours to keep**: for this project only or for all projects. The frame is drawn only in the preview and in the image export; **Copy as uu5String** and the agent's files stay clean. The page scrolls inside its own area and never runs under the frame.
- **Edit and delete**: the pencil (✎) next to a frame opens the same steps again with the link and the area it has now already chosen, and lets you rename it or change where it is visible (this project only / all projects). The trash can (🗑) moves it to the trash.
- The built-in frame of uuManagementKit is now called **uuApp default**.

### Fixes
- The dialog of a frame closes at once and the frame is written in the background (the screen pulses until it is done).

If you run 0.3.0 or newer, **Download** in the update strip installs this version and restarts the app by itself.

### Requirements
- Claude Code (the app offers to install it) and a Claude account, **or** Codex (the Codex CLI or the ChatGPT app) signed in.
- The plugins come from the uuCodebase marketplace over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.
- Plus4U documents need the `uubookkit` / `uumanagementkit` plugins of the uuAiMarketplace, Node.js (`npx`) and a Plus4U sign-in.

### Downloads
- `uu5Mock-Studio-0.10.0-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.10.0-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.
