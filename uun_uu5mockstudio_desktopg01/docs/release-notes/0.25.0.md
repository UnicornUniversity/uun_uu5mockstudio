## uu5Mock Studio 0.25.0

### New: Plus4U
- **Sign in to Plus4U** with the account button next to New Project (and in the project toolbar): your photo shows when you are signed in; when the sign-in expires the button goes back to the person icon. Google sign-in is remembered, so signing in again is one click.
- **Link a project to a uuManagementKit document, keyTask or portal** (paste its address). The toolbar shows the document with a dot when your changes are not uploaded (blue) or someone uploaded a newer version (orange).
- **Upload and Download** keep the project in the attachments of the document: one zip of the whole project plus the HTML of each screen. A newer upload by someone else is never overwritten without asking; a download first saves your current state into `.studio/backups`.
- **New project from a Plus4U document:** the arrow next to **New Project** downloads the project uploaded to a document (or makes an empty project linked to it).
- **Publish a screen or the sitemap onto a page of a document** (uu5String, validated by uuManagementKit): to the linked document or any other one, a new page or an existing one. The app remembers where each item went, so **Publish** then updates the same section in one click; the arrow chooses another page or document.
- The Plus4U features show only while you are signed in.

### Changed
- **A calmer top bar** in three groups: **Canvas | Sitemap | Plans**, **Project** (description, business rules, the Advanced view switch) with the comments, and Plus4U with your account. The tabs of the screens are gone (the screens are on the canvas).
- **Tools on the canvas:** Select, Edit (components) and the arrows between screens float on its left edge, the zoom sits in its bottom right corner. **Edit** is also on the bar above a selected screen.
- **One light work surface:** the canvas, the top bar and the sitemap share one lighter grey; the docked chat and the right panels (Edit, the page of the sitemap) are floating cards. Glass and dark mode follow.
- **The sitemap:** **Share** (like a screen: Image, SVG, uu5String and Publish) instead of Export, icon tools, and a header without lines across it.
- **Screen menu:** **Use This Variant…** only when the screen has variants; **Undo / Redo Screen Change** are gone (Edit → Undo / Redo does it).

### Requirements
- Claude Code (the app offers to install it) and a Claude account, **or** Codex (the Codex CLI or the ChatGPT app) signed in.
- Picture generation additionally needs an OpenAI API key (optional).
- The plugins come from the uuCodebase marketplace over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.
- Plus4U documents need the `uubookkit` / `uumanagementkit` plugins of the uuAiMarketplace, Node.js (`npx`) and a Plus4U sign-in.

### Downloads
- `uu5Mock-Studio-0.25.0-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.25.0-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.
