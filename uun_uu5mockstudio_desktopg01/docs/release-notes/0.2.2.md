## uu5Mock Studio 0.2.2

### What's new
- **The ⋯ menu in the toolbar is gone.** Everything it held is in the application menu: *Offline Mode*, *Warm Up CDN Cache* and *Clear CDN Cache* are under **View > Offline Use**, the Glass Effect under **View > Appearance**, updates under **Help**. A small *Offline* badge shows in the toolbar while offline mode is on.
- **Glass Effect fixes.** The Stop button is visible again while Claude works (it was white on white), the active Inspector toggle stays blue, the chat input area is its own frosted sheet so the history no longer runs into the prompt, and the selection bar of a screen sits below the floating toolbar.

Everything else is as in 0.2.1 (updates from GitHub, menus by topic, inspector with several marked components, icon palettes, a screenshot and clicks for the agent).

### Requirements
- Claude Code (the app offers to install it) and a Claude account.
- The plugins come from the uuCodebase marketplace over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.

### Downloads
- `uu5Mock-Studio-0.2.2-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.2.2-arm64.zip` – the same app as a zip.

The builds are **not code-signed**: on macOS open the app with right click > Open the first time. Installing an update is manual for the same reason (download, open, replace the app).
