## uu5Mock Studio 0.9.3

### New
- **Environments of a Page**: a page can be shown in the shell of uuManagementKit (top bar, left menu, route header with breadcrumb, title and buttons). The environment is drawn around the content only in the preview and in the image export; **Copy as uu5String** and the agent's files stay clean.
- **Plus4U documents on the dashboard**: a link to a uuBookKit / uuManagementKit document can be pasted on the dashboard already. The document is read there and moves into the project that is made for it.
- **Real page as the picture**: a window with the real page of a document lets you sign in to Plus4U and use **Use this page as the picture**; that picture replaces the one of the card and the one the agent gets. Whole-page pictures wait until the page is quiet (pictures and data loaded).

### Fixes
- Plus4U documents: the document is read whole and its pictures load in the preview.
- uu5String export keeps text colours and the content of inactive tabs.

If you run 0.3.0 or newer, **Download** in the update strip installs this version and restarts the app by itself.

### Requirements
- Claude Code (the app offers to install it) and a Claude account, **or** Codex (the Codex CLI or the ChatGPT app) signed in.
- The plugins come from the uuCodebase marketplace over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.
- Plus4U documents need the `uubookkit` / `uumanagementkit` plugins of the uuAiMarketplace, Node.js (`npx`) and a Plus4U sign-in.

### Downloads
- `uu5Mock-Studio-0.9.3-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.9.3-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.
