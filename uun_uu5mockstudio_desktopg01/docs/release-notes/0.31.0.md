## uu5Mock Studio 0.31.0

### Added
- **Copy a screen into another project.** Select a screen and press **⌘C** (or **⋯ → Copy screen**), open another project and press **⌘V** on its canvas. The screen takes along its pictures, notes, business rules and description; a taken name gets `-2`, the rules get the next free numbers, a different picture with the same name is saved under a new name. The message after the paste names what came along and the links to screens the project does not have. **Copy to project…** in the context menu (and **Screen → Copy to Project**) does it in one step. ⌘V in the same project duplicates the screen.

### Changed
- **The welcome tour shows what is new** (Help → Welcome Tour…): new cards for **Annotate**, **Plan mode**, the **sitemap** and **Plus4U documents** (Publish, Upload / Download), and the other cards are brought up to date (templates on the dashboard, links as Reference or Sitemap, variants and flow, the Edit mode, brand guidelines, the Share formats). The simple view skips the Plan and frame cards, and the card keeps its height from one card to the next. **The tour opens once after this update** also for those who have seen it before.

- **Comments on screens are hidden.** What the agent should change is an **annotation**, what it should know is a **note**; the review comments, kept only in the project folder, did not reach the reviewers. The speech bubble in the top bar and on the screens, **Comment on this** in the Edit mode and the Comments filter on the dashboard are gone. Comments a project already has stay in its files (`<screen>.comments.json`) and still go into the Project ZIP and the specification.

### Fixed
- **It is visible again that a project has business rules.** The **Project** button in the top bar carries the number of rules (in the Advanced view), as the toolbar icon did before the top bar was redone; its tooltip says the agent follows them.
- **A deleted screen leaves the sitemap.** Its page is removed from the sitemap (its sub-pages move up into its place; the root of the map only loses the link), the confirmation says so, the sitemap as it was before is kept as its previous version and the removed pages are noted in `.studio/removed-screen-memory.md`.

### Requirements
- Claude Code (the app offers to install it) and a Claude account, **or** Codex (the Codex CLI or the ChatGPT app) signed in.
- Picture generation additionally needs an OpenAI API key (optional).
- The plugins come from the uuCodebase marketplaces over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.
- Plus4U documents need the `uubookkit` / `uumanagementkit` plugins (the app installs them), Node.js (`npx`) and a Plus4U sign-in.

### Downloads
- `uu5Mock-Studio-0.31.0-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.31.0-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.
