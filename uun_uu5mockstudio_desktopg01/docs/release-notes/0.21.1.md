## uu5Mock Studio 0.21.1

### Changed
- **Pages from a link extend a sitemap that exists.** In a project that already has a sitemap, the pages you hand to the agent no longer start a new map: the agent goes through them and proposes how to extend or change the sitemap of the project (where each page belongs, what to merge, what to leave out). Nothing is replaced until you approve its plan.
- **The picker says what its buttons do.** With a sitemap in the project they read **Hand to the agent to extend the sitemap** and **Replace the sitemap**.
- **Handing pages to the agent is visible.** Nothing is sent at that moment: a note says how many pages are attached to your next message, the card of the link shows how many pages you picked, and the cursor is back in the message field.

### Requirements
- Claude Code (the app offers to install it) and a Claude account, **or** Codex (the Codex CLI or the ChatGPT app) signed in.
- The plugins come from the uuCodebase marketplace over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.
- Plus4U documents need the `uubookkit` / `uumanagementkit` plugins of the uuAiMarketplace, Node.js (`npx`) and a Plus4U sign-in.

### Downloads
- `uu5Mock-Studio-0.21.1-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.21.1-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.
