## uu5Mock Studio 0.35.2

### Changed
- **Start from an existing component right from the chat.** Pick the component with **@** and say what you want – *redesignuj existující komponentu @repo/…/header.js* or *další komponenta CourseList podle @repo/…/header.js*. A message with an @repo/ component file and words like *redesign, extend, rozšiř, další, nová, podle, based on* opens the Start from an existing component dialog filled in from the message: the file, extend or new, the name and what it should do. Cancel it and send again to send the message as it is.
- **Another component in the same project.** In a project already made from an existing component, **Project ▾ → Another from an existing component…** starts the next one (the item used to be hidden there).
- **The repository strip above the chat** shows read-only for Claude as a lock (the words are in its tooltip), so the repository's name has room in the narrow chat.

### Requirements
- Claude Code (the app offers to install it) and a Claude account, **or** Codex (the Codex CLI or the ChatGPT app) signed in.
- Picture generation additionally needs an OpenAI API key (optional).
- The plugins come from the uuCodebase marketplaces over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.
- Plus4U documents need the `uubookkit` / `uumanagementkit` plugins (the app installs them), Node.js (`npx`) and a Plus4U sign-in.

### Downloads
- `uu5Mock-Studio-0.35.2-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.35.2-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.
