## uu5Mock Studio 0.30.1

### Changed
- **A project with only a sitemap opens on the map:** when the project has a sitemap and no screen yet, it opens on the Sitemap instead of an empty canvas.
- **Annotating a page of the sitemap:** the box at the top of the page panel is gone; Annotate is an icon in the header of the panel, next to ×, with the numbers of the page's annotations on it. The panel starts with the settings of the page.
- **The row above the map:** the note on the whole map stays on the left, the tools of the view (Real links, Annotate, search, fold, Share) are on the right.

### Fixed
- **The numbers of annotations have no gaps:** after an annotation or a link is removed, the others are numbered 1, 2, 3… again, and the links `[#n]` in your text and the numbers on the screens and the map follow.

### Requirements
- Claude Code (the app offers to install it) and a Claude account, **or** Codex (the Codex CLI or the ChatGPT app) signed in.
- Picture generation additionally needs an OpenAI API key (optional).
- The plugins come from the uuCodebase marketplaces over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.
- Plus4U documents need the `uubookkit` / `uumanagementkit` plugins (the app installs them), Node.js (`npx`) and a Plus4U sign-in.

### Downloads
- `uu5Mock-Studio-0.30.1-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.30.1-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.
