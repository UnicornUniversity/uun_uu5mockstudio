## uu5Mock Studio 0.3.3

### What's new
- **Components from the libraries in the chat.** Type `@` and a few letters to mention a component of Uu5Elements, Uu5Forms, Plus4U5Elements and the other libraries (the documentation of the uu5-development plugin), or open the cube button next to the message field: search, filter by library, a structured description with a table of props and a link to the documentation. Claude gets the description, the props and the reference file of every mentioned component.
- **Components of a screen linked in the text.** A component picked in the preview is linked in your message where the cursor is (`[#1 Box “…”]`), so you can write "change this one `[#1 …]` and that one `[#2 …]`". Picking works like in the inspector: a plain click picks one, Shift / ⌘ / Ctrl + click adds or removes more.
- **Inspector**
  - A list of plain strings with known items (such as `nestingLevelList`) is a multi choice.
  - A text that is an LSI (`{ cs, en }`, `t("Ano", "Yes")`, `<T lsi>`, a constant, `useLsi`) is shown as its texts with a switch of the languages and edited where it is written. A prop that points to a variable shows the value of the variable.
  - A list of actions (`actionList`, `itemList` of ActionGroup, `iconRightList`) opens in a window: all actions, a form built from the grammar of an action, add, duplicate, delete and move. An action that is a component is edited as code.
  - A cross closes the panel, and the bar above a selected screen has an inspector button and can be moved.
  - Scrolling over a screen: with the inspector on it moves the canvas (⌥ scrolls the screen); otherwise it scrolls the screen (⌥ moves the canvas).
- **Dialogs** are consistent: a cross in the header closes every dialog that only shows or edits something. Icon fields look and work the same everywhere.
- **Unlinking the git repository asks first** (the cross on the repository strip and Project > Git Repository > Unlink).
- **First-run welcome tour**, **Escape** closes the topmost dialog, the branch and context menus open where they should in the Glass Effect, and several Glass Effect fixes (Stop, inspector buttons, menus).

If you run 0.3.0 or newer, **Download** in the update strip installs this version and restarts the app by itself.

### Requirements
- Claude Code (the app offers to install it) and a Claude account.
- The plugins come from the uuCodebase marketplace over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.

### Downloads
- `uu5Mock-Studio-0.3.3-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.3.3-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.

After that, updates from inside the app (**Check for Updates…** > **Download**) install themselves and need no such step.
