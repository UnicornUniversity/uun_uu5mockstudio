## uu5Mock Studio 0.3.10

### What's new
- **Component tree of a screen or of one component** (Screen > Show Component Tree…, the context menu, and **Show component tree** in the inspector for the component you picked). Drag and drop rearranges the components: before, after or inside another one. **Regenerate the screen** moves them straight in the file where it is safe; the screen shows the result and a bar asks you to **Keep** or **Undo** it. What cannot be moved there (conditions, lists, other components) goes to the agent, with the reasons, only after you keep.
- **Undo / Redo of the changes the app makes to a screen** (Edit > Undo / Redo, ⌘Z, ⇧⌘Z): an edit in the inspector, a text, a list of actions, a rearrangement. In a text field the same keys undo the typing. It works without the inspector, with the last change in the project.
- **Inspector**: choosing a component in the breadcrumb moves the frame on the page to it, so a Grid can be marked by itself.
- **Plan mode**: a change of the order of components in a plan is reported to the agent (it was lost before).

If you run 0.3.0 or newer, **Download** in the update strip installs this version and restarts the app by itself.

### Requirements
- Claude Code (the app offers to install it) and a Claude account.
- The plugins come from the uuCodebase marketplace over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.

### Downloads
- `uu5Mock-Studio-0.3.10-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.3.10-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.

After that, updates from inside the app (**Check for Updates…** > **Download**) install themselves and need no such step.
