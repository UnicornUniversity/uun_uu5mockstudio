## uu5Mock Studio 0.3.0

### What's new
- **The app updates itself on macOS.** When a newer version is announced, **Download** in the strip above the chat now downloads the update, checks it (size, SHA-256, identity and signature of the app), restarts the app and starts the new version. No more dragging the DMG. If the app cannot replace itself (for example it is in a folder you cannot write to), Download opens the installer in the browser as before.
- No quarantine warnings after an in-app update: the file is downloaded by the app, not by the browser.

**Install this version by hand once** (from the DMG, see below). Older versions cannot update themselves; from this one on, updates go by themselves.

Everything else is as in 0.2.5 (Show / Hide inspector in the screen menu, Glass Effect menu fixes, no toolbar menu: Offline Use under View, ...).

### Requirements
- Claude Code (the app offers to install it) and a Claude account.
- The plugins come from the uuCodebase marketplace over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.

### Downloads
- `uu5Mock-Studio-0.3.0-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.3.0-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**. Drag the app to Applications and open it. If macOS blocks it, open System Settings > Privacy & Security and click **Open Anyway**; if it says "damaged", run `xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"` in Terminal once.
