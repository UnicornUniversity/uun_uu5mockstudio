## uu5Mock Studio 0.7.0

### What's new
- **Codex (OpenAI) as a second AI backend**: if Codex is installed and signed in on this computer, its models appear in the model list next to those of Claude Code. The list is built from what is really usable (installed and signed in) and shows the real models of each provider; the choice is remembered. A conversation keeps a separate session per provider, so you can switch between them.
- **Codex builds screens the same way**: before it writes a screen it has to read the uu5-mockup, uuGDS and uu5-knowledge files, and a run that wrote a screen without them is sent back once to read them and rework the screen. It uses the same preview tools as Claude (open and reload the page, console, snapshot, click, screenshot, component structure). It writes only into the project folder (sandbox); in Plan mode it cannot write at all.
- **Plugins in Codex**: the uu5 plugins are installed into Codex when it is first used, and **Help → Codex & Plugins…** shows their versions, checks for newer ones and updates them (Codex does not update them by itself). The dialog looks like the one of Claude Code.
- **Menu follows what you use**: the Claude Code item in Help is hidden when only Codex is usable.
- **Fix: components of a screen written with an alias** (`const E = Uu5Elements;` and `<E.Block>`, which Codex likes to write) could not be selected or edited. They are recognised now, under their real names (Uu5Elements.Block). The agents are also told to write plain namespaces.
- **The repository strip** of a project sits above the Agent / Components tabs and stays there on both tabs.

If you run 0.3.0 or newer, **Download** in the update strip installs this version and restarts the app by itself.

### Requirements
- Claude Code (the app offers to install it) and a Claude account, **or** Codex (the Codex CLI or the ChatGPT app) signed in. At the moment the first-run wizard still asks for Claude Code.
- The plugins come from the uuCodebase marketplace over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source. For Codex the marketplace folder is kept in sync by the uuAiMarketplace extension of VS Code.

### Known limits of Codex
- Its answers arrive in whole messages, not word by word.
- It can read any file your user can read (Claude is limited to the project and the linked repository); writing outside the project is blocked.
- Its token counts are per request and differ from those of Claude.

### Downloads
- `uu5Mock-Studio-0.7.0-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.7.0-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.
