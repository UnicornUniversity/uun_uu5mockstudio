## uu5Mock Studio 0.38.5

### Fixed
- **Plan mode no longer stays on by itself.** Actions that prepare a plan (Change @screen from the structure of a screen, Revise the plan, proposing a sitemap, pages picked from a link) switch Plan on for the next message only; then the message field goes back to Agent. Before, Plan stayed on, so later messages (for example annotations) were only planned and the agent reported that it could not edit the file. A Plan you choose yourself stays on as before.
- **A message sent in Plan mode has a "Plan" label** in the chat, so you can see how it went.
- **Only a real plan becomes a draft plan.** An answer in Plan mode without a component tree, a sitemap, questions or a heading stays an ordinary message of the chat instead of a plan titled after its first sentence. In Plan mode the agent also knows that the file tools are switched off on purpose and answers with a plan of the change.
- **Copy as uu5String leaves out `nestingLevel` added by a parent.** Components inside Uu5Bricks.Background, Card, Layout.Item or Tile no longer get `nestingLevel="areaCollection"` (or `boxCollection`, `inline`) in the exported uu5String; a `nestingLevel` you wrote yourself stays.

### Requirements
- Claude Code (the app offers to install it) and a Claude account, **or** Codex (the Codex CLI or the ChatGPT app) signed in.
- Picture generation additionally needs an OpenAI API key (optional).
- The plugins come from the uuCodebase marketplaces over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.
- Plus4U documents need the `uubookkit` / `uumanagementkit` plugins (the app installs them), Node.js (`npx`) and a Plus4U sign-in.

### Downloads
- `uu5Mock-Studio-0.38.5-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.38.5-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.
