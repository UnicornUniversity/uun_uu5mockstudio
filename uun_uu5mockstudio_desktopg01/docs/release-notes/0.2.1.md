## uu5Mock Studio 0.2.1

### What's new
- **Updates from GitHub.** *Check for Updates…* now looks at the releases of this repository. When a newer version is published, a strip above the chat offers **Download** (the installer for your system opens in the browser), **Notes** (the release page) and **Later**. The app also checks in the background a few seconds after start, at most every 6 hours. It needs no code signing, and only pages of this repository are ever opened.
- Texts of the update messages are in English.

Everything else is as in 0.2.0 (menus by topic, inspector with several marked components, icon palettes with the uuBml icons and states, Glass Effect on macOS, a screenshot and clicks for the agent).

### Requirements
- Claude Code (the app offers to install it) and a Claude account.
- The plugins come from the uuCodebase marketplace over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.

### Downloads
- `uu5Mock-Studio-0.2.1-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.2.1-arm64.zip` – the same app as a zip.

The builds are **not code-signed**: on macOS open the app with right click > Open the first time. Installing an update is manual for the same reason (download, open, replace the app).
