## uu5Mock Studio 0.3.2

### What's new
- **Welcome tour.** On the first run the app shows six cards with the key features: describing a screen, the chat context, the canvas, the inspector, the project memory, and sharing and updates. It is shown once; **Help > Welcome Tour…** opens it again.
- **Escape closes dialogs.** The topmost open dialog (plugins and setup, About, rules, descriptions, icons, confirmations) closes on Escape even when the keyboard focus is not inside it.
- **Screens and notes stay clear of a floating chat.** *Fit* and the zoom to a screen keep the screens and their notes out from under a floating chat, and notes count as part of the picture.

If you run 0.3.0 or newer, **Download** in the update strip installs this version and restarts the app by itself.

### Requirements
- Claude Code (the app offers to install it) and a Claude account.
- The plugins come from the uuCodebase marketplace over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.

### Downloads
- `uu5Mock-Studio-0.3.2-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.3.2-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.

After that, updates from inside the app (**Check for Updates…** > **Download**) install themselves and need no such step.
