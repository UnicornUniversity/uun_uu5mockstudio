## uu5Mock Studio 0.9.2

### Fixes
- **Plus4U documents with long sections**: uuManagementKit gives a long section only in part, so its preview stayed blank and the agent got a cut copy. The app now loads such sections whole.
- **Pictures of a document**: logos and pictures stored in the document itself (uuManagementKit) are downloaded and shown in the preview and in the picture the agent sees.
- **One broken section no longer blanks the preview**: a section that cannot be shown gets a short note, the rest of the page stays.
- **Sign-in to Plus4U**: the card says it is waiting for the browser only while you sign in, then it shows that the document is loading.
- **Glass Effect**: the **Sign in** and ✕ buttons of a document card under the message field were white on white.

### Known issue
- A table made with Uu5TilesBricks may still be missing in the app's preview of a document (it shows a note instead); the agent reads its content from the document.

If you run 0.3.0 or newer, **Download** in the update strip installs this version and restarts the app by itself.

### Requirements
- Claude Code (the app offers to install it) and a Claude account, **or** Codex (the Codex CLI or the ChatGPT app) signed in.
- The plugins come from the uuCodebase marketplace over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.
- Plus4U documents need the `uubookkit` / `uumanagementkit` plugins of the uuAiMarketplace, Node.js (`npx`) and a Plus4U sign-in.

### Downloads
- `uu5Mock-Studio-0.9.2-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.9.2-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.
