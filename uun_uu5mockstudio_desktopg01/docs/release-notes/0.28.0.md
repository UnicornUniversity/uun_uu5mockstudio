## uu5Mock Studio 0.28.0

### New
- **Dashboard shows what waits for you:** a strip "Needs your attention" lists the projects with a plan to approve, variants to choose, or open comments (on screens or in the sitemap). Project cards carry small tags for the same (and for notes). The filters above the list (All, Plan to approve, Variants to choose, Comments) and the new "Waiting for you" item in the sidebar, with the number of such projects, narrow the list. "Templates" is now also in the sidebar.
- **Plugins of uuBookKit and uuManagementKit are kept up to date:** the app installs `uubookkit` and `uumanagementkit` (marketplace `uu-business-products-mp`) when they are missing, and "Check for Plugin Updates" covers every marketplace it takes plugins from, in Claude Code and in Codex. They are recommended: a missing one never blocks the app. More marketplaces can be listed under `extra` in `prerequisites.json`.

### Changed
- **Calmer dashboard:** the title is "Workbench", the list is headed "Your projects", the glowing halo around the prompt is gone, the templates and buttons use the accent colour, and the rounded shapes match the rest of the app with the glass effect on or off.

### Requirements
- Claude Code (the app offers to install it) and a Claude account, **or** Codex (the Codex CLI or the ChatGPT app) signed in.
- Picture generation additionally needs an OpenAI API key (optional).
- The plugins come from the uuCodebase marketplaces over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.
- Plus4U documents need the `uubookkit` / `uumanagementkit` plugins (the app now installs them), Node.js (`npx`) and a Plus4U sign-in.

### Downloads
- `uu5Mock-Studio-0.28.0-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.28.0-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.
