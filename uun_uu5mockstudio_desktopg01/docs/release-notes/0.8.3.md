## uu5Mock Studio 0.8.3

### What's new
- **Fix: the update strip is visible in an open project with the Glass effect.** It was hidden behind the floating toolbar; now it floats under the toolbar (and the project description), and the canvas keeps room for it.

If you run 0.3.0 or newer, **Download** in the update strip installs this version and restarts the app by itself. With the Glass effect on, versions before 0.8.3 show the strip only on the dashboard (or turn Glass off in the View menu).

### Requirements
- Claude Code (the app offers to install it) and a Claude account, **or** Codex (the Codex CLI or the ChatGPT app) signed in.
- The plugins come from the uuCodebase marketplace over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.

### Downloads
- `uu5Mock-Studio-0.8.3-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.8.3-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.
