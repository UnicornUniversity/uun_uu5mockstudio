## uu5Mock Studio 0.27.0

### Added
- **Web sites with language versions are read once.** A site that names its languages (`hreflang` in the sitemap.xml or in the head of the page) is listed in the picker in the language of the page you gave; the other languages are translations of its pages, not pages, and the language switcher is not a page either. A site with 664 addresses in five languages becomes 134 pages. A line above the tree names the languages, and **Show every language as pages** brings the old listing back.
- **The agent is told the site is multilingual:** one page per entry, the other languages as translations (LSI).
- **Fit screen** in the menu of a screen zooms to that one screen.

### Changed
- **The Plans menu is clearer:** a "Plans" and a "Sitemap" section, and the four ways to make a sitemap (From the screens, From a link…, Ask the agent…, Empty map) as lines with an icon and what each does.
- **The dotted background of the canvas is quieter:** fainter and sparser.

### Fixed
- **The bar over a screen can be grabbed again** after it is moved up into the top bar: the transparent top bar no longer takes its clicks.

### Requirements
- Claude Code (the app offers to install it) and a Claude account, **or** Codex (the Codex CLI or the ChatGPT app) signed in.
- Picture generation additionally needs an OpenAI API key (optional).
- The plugins come from the uuCodebase marketplace over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.
- Plus4U documents need the `uubookkit` / `uumanagementkit` plugins of the uuAiMarketplace, Node.js (`npx`) and a Plus4U sign-in.

### Downloads
- `uu5Mock-Studio-0.27.0-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.27.0-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.
