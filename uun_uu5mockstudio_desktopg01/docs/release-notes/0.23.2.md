## uu5Mock Studio 0.23.2

### Changed
- **The route layout skill is used reliably.** The agent must now read `mockup-route-layout` before it builds a screen with an application shell: Claude invokes it with the Skill tool, Codex has it among the files it must read.
- **Application and Route templates** use the simulated route header of that skill (`Uu5Elements.Text` title and `ActionGroup`, no Plus4U libraries) instead of `Plus4U5App.RouteHeader`, which left a standalone mockup blank.

### Requirements
- Claude Code (the app offers to install it) and a Claude account, **or** Codex (the Codex CLI or the ChatGPT app) signed in.
- The plugins come from the uuCodebase marketplace over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.
- Plus4U documents need the `uubookkit` / `uumanagementkit` plugins of the uuAiMarketplace, Node.js (`npx`) and a Plus4U sign-in.

### Downloads
- `uu5Mock-Studio-0.23.2-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.23.2-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.
