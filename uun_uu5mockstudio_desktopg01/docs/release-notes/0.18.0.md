## uu5Mock Studio 0.18.0

### New
- **Text first, the map below it.** The card of a plan shows the text, then the **Sitemap** and the **Component tree**, each only when the plan has it (no more Map / Text switch). A plan about the whole structure has a map, a plan about one page has a component tree.
- **Fold and unfold branches** of the map (arrow on a page, **Fold all**, **Unfold all**); a big map starts folded below its second level.
- **The map stays editable after it is approved**, and its header shows how many pages already have a screen, so the map grows with the work: what is designed and what is not is visible in it.
- **Approving a map does not build it.** A plan that is only a sitemap has **Approve the map**: it agrees on the structure and builds nothing. Screens are created page by page (**Create the screen**) or for up to 8 selected pages (**Create the screens**, with a confirmation); a plan with a component tree builds only that screen. The agent is told never to build all pages of a map in one go.
- **A map from the screens that exist.** A plan without a sitemap has **Generate from the screens**: a first map made of the screens of the project and the links between them (the root is index / home, the pages below follow the links of the content, the rest goes under the root).
- **Real links over the map.** The **Real links** button draws, in orange, the links that the screens really have between two pages of the map and that the map does not show, and lists the pages without a screen and the screens that no page names (**+** adds one to the map). The map and the screens can be compared before building.

### Requirements
- Claude Code (the app offers to install it) and a Claude account, **or** Codex (the Codex CLI or the ChatGPT app) signed in.
- The plugins come from the uuCodebase marketplace over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.
- Plus4U documents need the `uubookkit` / `uumanagementkit` plugins of the uuAiMarketplace, Node.js (`npx`) and a Plus4U sign-in.

### Downloads
- `uu5Mock-Studio-0.18.0-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.18.0-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.
