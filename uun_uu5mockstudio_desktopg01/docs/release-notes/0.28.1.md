## uu5Mock Studio 0.28.1

### Fixed
- **Sitemap and plans have the surface of the canvas:** the full view of the sitemap or a plan no longer has a tinted background of its own (with the Glass effect) and shows the same dots as the canvas, so switching between Canvas, Sitemap and Plans does not change the background.
- **Esc in the sitemap closes the panel of the page:** with a page selected, Esc closes the panel on the right, like its cross. It never leaves the sitemap or a plan for the canvas; the Canvas button does that.

### Requirements
- Claude Code (the app offers to install it) and a Claude account, **or** Codex (the Codex CLI or the ChatGPT app) signed in.
- Picture generation additionally needs an OpenAI API key (optional).
- The plugins come from the uuCodebase marketplaces over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.
- Plus4U documents need the `uubookkit` / `uumanagementkit` plugins (the app now installs them), Node.js (`npx`) and a Plus4U sign-in.

### Downloads
- `uu5Mock-Studio-0.28.1-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.28.1-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.
