## uu5Mock Studio 0.9.1

### What's new
- **Glass Effect everywhere** (macOS, View → Appearance → Glass Effect): the whole app now uses the same glass materials in light and dark. The chat and dashboard sidebars are a soft tint over a light colour wash; the toolbar, description strip, inspector and selection bar are frosted glass floating over the canvas; menus, dialogs (Templates, Save as template, confirmations, About…), toasts, dashboard cards, template chips and buttons are glass cards and capsules. Before, only a few panels were glass. With **Reduce transparency** on in the macOS accessibility settings the effect switches itself off; without the effect the app looks as before.

### Fixes
- **Dashboard**: the shadows of the project cards at the left and right edge are no longer cut off.

If you run 0.3.0 or newer, **Download** in the update strip installs this version and restarts the app by itself.

### Requirements
- Claude Code (the app offers to install it) and a Claude account, **or** Codex (the Codex CLI or the ChatGPT app) signed in.
- The plugins come from the uuCodebase marketplace over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.
- Plus4U documents need the `uubookkit` / `uumanagementkit` plugins of the uuAiMarketplace, Node.js (`npx`) and a Plus4U sign-in.

### Downloads
- `uu5Mock-Studio-0.9.1-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.9.1-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.
