## uu5Mock Studio 0.24.0

### Changed
- **One Settings window.** Settings that were spread over View, Help and Project are now in **Settings…** (⌘, in the app menu on macOS, **File → Settings…** on Windows and Linux): your role, the projects folder, theme and Glass effect, Claude Code and Codex, the uuAiChat MCP server, picture generation and offline use. View now holds only the canvas (zoom, layout) and Help only the Welcome Tour and Check for Updates.
- **Picture generation.** The agent can create a picture for a design with the OpenAI image model and save it into `assets/` (new tool `generate_image`, also for Codex). It is off by default: switch it on and enter an OpenAI API key in **Settings → Integrations → Picture generation**. The key is stored encrypted by the operating system (Electron `safeStorage`), outside `app-state.json`; the credentials of Codex are not read.
- The model is set in the same dialog (field **Model**; empty means `gpt-image-2`). OpenAI offers image models only to accounts with enough limits (a verified organization, a paid tier); with a limit of 0 the agent reports it and falls back to SVG or a placeholder.
- At most 4 pictures are generated for one message and the same description is never generated twice (the cost guard).
- The description of the picture goes to OpenAI; this is the only new network call and it happens only when the feature is on.

### Requirements
- Claude Code (the app offers to install it) and a Claude account, **or** Codex (the Codex CLI or the ChatGPT app) signed in.
- Picture generation additionally needs an OpenAI API key (optional).
- The plugins come from the uuCodebase marketplace over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.
- Plus4U documents need the `uubookkit` / `uumanagementkit` plugins of the uuAiMarketplace, Node.js (`npx`) and a Plus4U sign-in.

### Downloads
- `uu5Mock-Studio-0.24.0-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.24.0-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.
