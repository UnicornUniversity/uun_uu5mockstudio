## uu5Mock Studio 0.10.1

### New
- **More parts for the content area of a frame**: when choosing the content area of a frame from a link, hold **Shift** while clicking an element (or dragging a rectangle) to add another part; Shift+click on a part again takes it away. The content area is the smallest rectangle around all the chosen parts (a dashed line shows it), so it also works when the content is not in one element. **＋ Add part** does the same without the keyboard, and Shift+Enter adds the highlighted element. A click without Shift (or Enter) finishes; Esc goes back to browsing and keeps what is chosen.

### Fixes
- Choosing a part after scrolling the page no longer drops what scrolled out of the window (a header, a menu) from the frame: the page is taken from its top, and a rectangle drawn on the page scrolls with the page.

If you run 0.3.0 or newer, **Download** in the update strip installs this version and restarts the app by itself.

### Requirements
- Claude Code (the app offers to install it) and a Claude account, **or** Codex (the Codex CLI or the ChatGPT app) signed in.
- The plugins come from the uuCodebase marketplace over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.
- Plus4U documents need the `uubookkit` / `uumanagementkit` plugins of the uuAiMarketplace, Node.js (`npx`) and a Plus4U sign-in.

### Downloads
- `uu5Mock-Studio-0.10.1-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.10.1-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.
