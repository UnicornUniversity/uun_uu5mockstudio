## uu5Mock Studio 0.2.4

### Fixes
- **Glass Effect: menus open where they should.** The branch menu and the context menu of the chat opened half outside the floating chat; they now open at their button.
- Drop-down menus are almost opaque in the Glass Effect, so the text behind them no longer shows through.

Everything else is as in 0.2.3 (the macOS app opens as an unsigned app, no toolbar menu: Offline Use under View, updates from GitHub, ...).

### Requirements
- Claude Code (the app offers to install it) and a Claude account.
- The plugins come from the uuCodebase marketplace over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.

### Downloads
- `uu5Mock-Studio-0.2.4-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.2.4-arm64.zip` – the same app as a zip.

The builds are **not notarized by Apple**. Drag the app to Applications and open it. If macOS blocks it, open System Settings > Privacy & Security and click **Open Anyway**; if it says "damaged", run `xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"` in Terminal once.
