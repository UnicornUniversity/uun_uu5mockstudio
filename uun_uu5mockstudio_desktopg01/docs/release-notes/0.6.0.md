## uu5Mock Studio 0.6.0

### What's new
- **Edit mode** (the pencil button over the screens, or **I**): the screen stops reacting to its own clicks and every gesture edits the screen's file. The screens say "editing"; the **Components** tab opens next to them.
- **Add components by dragging**: drag a component from the **Components** tab onto a screen; a line shows whether it goes before, after or inside a component. The app has ready code for the common components (Text, Block, Button, Tabs, form fields and more) and builds it from the documentation for most of the others. What it cannot do (a component that needs data, a library the screen does not import, a place the file does not allow) is given to the agent with one click (**Ask the agent**).
- **Move by dragging**: drag a component to another place of the same screen.
- **Delete and copy**: mark components (Shift-click for more) and press **Delete** to remove them or **⌘D** to copy them; the panel has **Delete / Duplicate component** too. **⌘Z** undoes, **Esc** unmarks and then leaves the mode. The component you added, moved or copied is marked again.
- **Edit a text in place**: double click a text, type, press Enter. The text is changed where it is written in the file (also in a constant or in one language of an LSI).
- **Lists of objects** (the actions of an action list, an `itemList`): click an item, drag it to another place of its list, **Delete** or **⌘D** it, and use **Add item after this one** in the panel.

Every change made this way is one step of **Undo**.

If you run 0.3.0 or newer, **Download** in the update strip installs this version and restarts the app by itself.

### Requirements
- Claude Code (the app offers to install it) and a Claude account.
- The plugins come from the uuCodebase marketplace over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.

### Downloads
- `uu5Mock-Studio-0.6.0-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.6.0-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.

After that, updates from inside the app (**Check for Updates…** > **Download**) install themselves and need no such step.
