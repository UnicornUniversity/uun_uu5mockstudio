## uu5Mock Studio 0.23.0

### Added
- **Search in the sitemap.** A small magnifier on the toolbar of the map (next to Fold all, Unfold all and Export) opens a search field. It looks in the title, screen file, note and comment of every node (pages, sheets, sections, groups, links), ignoring case and diacritics. The matches are marked, the rest is dimmed, folded branches with a match unfold by themselves. **Enter** / **Shift + Enter** (or ↑ ↓) goes from one match to the next, **Esc** clears the search.
- **Link an existing screen to a page.** In the settings of a page, **Link an existing screen…** under *Screen file* offers the screens of the project (the ones no page names yet first), so a screen that already exists can be attached to a node of the map, for example the root.

### Fixed
- **Open the screen** in the sitemap now leaves the full view of the map and shows the screen on the canvas.

### Requirements
- Claude Code (the app offers to install it) and a Claude account, **or** Codex (the Codex CLI or the ChatGPT app) signed in.
- The plugins come from the uuCodebase marketplace over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.
- Plus4U documents need the `uubookkit` / `uumanagementkit` plugins of the uuAiMarketplace, Node.js (`npx`) and a Plus4U sign-in.

### Downloads
- `uu5Mock-Studio-0.23.0-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.23.0-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.
