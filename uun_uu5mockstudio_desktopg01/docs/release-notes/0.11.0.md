## uu5Mock Studio 0.11.0

### Added
- **Your role**: the first run asks what you design (UI/UX, Web and marketing, Solution architect, Quick start) and presets the dashboard, Eco, the Share format and the simple view. Change it in Help → Your Role…; the **Advanced** button switches the simple view.
- **Web templates**: a whole page of a web site (home page, landing page, page) drawn full width.
- **Flow between screens**: arrows on the canvas from a screen to the screens it links to; the inspector has a **Leads to** row for buttons and links.
- **Variants of a screen** (Screen → Variants…): the agent writes 2–4 variants next to the original. On the canvas the original and its variants share a colour, sit on a tinted board with labels (Original, A, B …), and you choose in its header: select a label, then **Use A**.
- **Comments** for the people who review the design: on a screen or a component, with author, answers and resolving.
- **Pictures from the web**: the agent saves pictures of a public page into the project and uses them in a screen; the Project ZIP carries the pictures and videos the screens use.
- **Project specification**: File → Export → Project Specification (Markdown)… for the people who build it.

If you run 0.3.0 or newer, **Download** in the update strip installs this version and restarts the app by itself.

### Requirements
- Claude Code (the app offers to install it) and a Claude account, **or** Codex (the Codex CLI or the ChatGPT app) signed in.
- The plugins come from the uuCodebase marketplace over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.
- Plus4U documents need the `uubookkit` / `uumanagementkit` plugins of the uuAiMarketplace, Node.js (`npx`) and a Plus4U sign-in.

### Downloads
- `uu5Mock-Studio-0.11.0-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.11.0-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.
