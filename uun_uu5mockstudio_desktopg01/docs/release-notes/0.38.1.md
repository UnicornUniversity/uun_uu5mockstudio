## uu5Mock Studio 0.38.1

### Fixed
- **Share › Image: Copy and Drag work again.** Copying the picture of a screen to the clipboard and dragging it into a chat, a mail or a folder failed with “target closed while handling command” (or “The file is still being prepared”) for a screen that fits its frame, such as one in a portal layout that scrolls inside its own area.
- **Share › uu5String keeps the look of the screen.** Styles of the screen's CSS that apply through a parent (`.hero h1`, `.chips a`) now reach the elements inside `Uu5Bricks.Background` and other components that clone their children; the rules follow the cascade, so a reset like `h1 { font-size: 2em }` no longer wins over the screen's own rule; a text with a gradient keeps its gradient; and CSS variables (`var(--brand-…)`) in component props such as `gradient` are written as their values, because a document does not know them.
- **The Publish button of the Share menu** is wide enough for its icon, text and the arrow.

### Requirements
- Claude Code (the app offers to install it) and a Claude account, **or** Codex (the Codex CLI or the ChatGPT app) signed in.
- Picture generation additionally needs an OpenAI API key (optional).
- The plugins come from the uuCodebase marketplaces over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.
- Plus4U documents need the `uubookkit` / `uumanagementkit` plugins (the app installs them), Node.js (`npx`) and a Plus4U sign-in.

### Downloads
- `uu5Mock-Studio-0.38.1-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.38.1-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.
