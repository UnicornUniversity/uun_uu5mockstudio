## uu5Mock Studio 0.5.1

### What's new
- **No flicker when a screen renders again** (the agent or the inspector changed it, **Reload**): the new page loads in a second webview behind the shown one and replaces it when it has loaded and settled, so there is no white moment and nothing jumps, at any zoom. The scroll position is kept.
- **Tokens of every request** under the answer of the agent (also under a plan card): `17.3k tokens`, with the details on hover (input, output, cache, per model). Kept with the conversation.
- **Device size of a screen** can be changed again after switching it to a narrow size such as Mobile: the button stays in the title of the frame, and **Device size…** is in the screen menu (⋯ and right click).
- **Dashboard and projects**: update notices are visible on the dashboard, a project from the dashboard is named after its application / first screen, the pictures wait until the screens have rendered.

If you run 0.3.0 or newer, **Download** in the update strip installs this version and restarts the app by itself.

### Requirements
- Claude Code (the app offers to install it) and a Claude account.
- The plugins come from the uuCodebase marketplace over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.

### Downloads
- `uu5Mock-Studio-0.5.1-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.5.1-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.

After that, updates from inside the app (**Check for Updates…** > **Download**) install themselves and need no such step.
