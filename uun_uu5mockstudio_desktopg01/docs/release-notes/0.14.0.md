## uu5Mock Studio 0.14.0

### New
- **Readable screen flow**: the arrows between screens stay readable even when every screen links to every other one. Links of a menu (in a `nav`, header or footer, or several screen links next to each other) are hidden by default; they appear when you select a screen or point at it, and the new button with three lines next to the flow button draws all of them. Two screens that link to each other get one line with a head at both ends, arrows leave the side that faces the other screen, and the arrows of the selected (or pointed-at) screen are strong while the others fade.

### Fixed
- **uu5String keeps the look of the screen in a document**: a gradient or dark background written in the `style` of a `div` or `Uu5Bricks.Card` is not painted by a document (the section came out white, white text invisible). The export now writes it as `Uu5Bricks.Background` (the border radius and the padding of a card are kept; buttons and texts are never wrapped).
- **CSS variables**: `var(--brand-…)` in a style (also inside gradients) is written as its colour or font, because a document does not know the variables of the screen.

### Changed
- The Web templates (home, landing, page, product) tell the agent to paint sections, heroes and panels with `Uu5Bricks.Background` itself, so the preview looks like the document.
- The user guide no longer mentions the removed **Share…** button.

If you run 0.3.0 or newer, **Download** in the update strip installs this version and restarts the app by itself.

### Requirements
- Claude Code (the app offers to install it) and a Claude account, **or** Codex (the Codex CLI or the ChatGPT app) signed in.
- The plugins come from the uuCodebase marketplace over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.
- Plus4U documents need the `uubookkit` / `uumanagementkit` plugins of the uuAiMarketplace, Node.js (`npx`) and a Plus4U sign-in.

### Downloads
- `uu5Mock-Studio-0.14.0-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.14.0-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.
