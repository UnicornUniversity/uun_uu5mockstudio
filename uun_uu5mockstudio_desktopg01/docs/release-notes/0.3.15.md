## uu5Mock Studio 0.3.15

### What's new
- **Business rules**
  - **This project** shows the number of its rules, like **All projects**.
  - The sections (General, Screen: …) can be rolled up and opened again with a click on the heading; the choice is remembered.
  - **Deleting a screen also removes its rules and its description** (the confirmation says what goes with it; a copy is kept in `.studio/removed-screen-memory.md` of the project).
- **Library browser**: the **Default** column of the props is one plain line (a style clash had turned it into a big box); a long default is clipped and opens with a click.
- **Device size of a screen**: the menu is a normal-sized popover (the native one was huge at a small zoom of the canvas).
- **Fullscreen preview**: the chat and the notes always start minimized in their corners (chat bottom-left, notes bottom-right), wherever they were left the last time.

If you run 0.3.0 or newer, **Download** in the update strip installs this version and restarts the app by itself.

### Requirements
- Claude Code (the app offers to install it) and a Claude account.
- The plugins come from the uuCodebase marketplace over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.

### Downloads
- `uu5Mock-Studio-0.3.15-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.3.15-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.

After that, updates from inside the app (**Check for Updates…** > **Download**) install themselves and need no such step.
