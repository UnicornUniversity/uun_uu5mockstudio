## uu5Mock Studio 0.16.0

### New
- **Plans are files on the canvas.** Every plan from Plan mode is saved as its own Markdown file, `plans/<name>.md`, and shown as a card beside the screens. The card has a **read** mode (headings, lists, checklists, tables, the component tree, the questions, `[[screen.html]]` links that jump to the screen) and an **edit** mode for the Markdown (⌘E / Ctrl+E), saved as you type.
- A plan card can be hidden from the canvas (✕); **Show on canvas** in the chat brings it back.
- **One plan, two views.** The card in the chat and the file follow each other: edit either one, or the file in any editor, and the other updates. **Approve & build** on the canvas card builds the plan as written. The chat card has **Show on canvas**.

### Changed
- The Markdown of plans has a richer renderer (h1–h4, nested lists, tables, quotes); chat messages keep the small one.
- **Fit all screens** takes the plan cards in.
- A **revised plan** (answers, Revise…) replaces the text of the same file and card instead of adding a second one.
- The plan card in the chat is compact when the plan is a file: the text is read on the canvas, the component tree is behind a button, the questions and Build / Revise / Discard stay.
- The component tree on the card is a wrapping list (names, notes, ×N, R, D tags) instead of a clipped block.

### Requirements
- Claude Code (the app offers to install it) and a Claude account, **or** Codex (the Codex CLI or the ChatGPT app) signed in.
- The plugins come from the uuCodebase marketplace over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.
- Plus4U documents need the `uubookkit` / `uumanagementkit` plugins of the uuAiMarketplace, Node.js (`npx`) and a Plus4U sign-in.

### Downloads
- `uu5Mock-Studio-0.16.0-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.16.0-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.
