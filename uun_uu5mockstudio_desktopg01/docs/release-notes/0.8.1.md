## uu5Mock Studio 0.8.1

### What's new
- **Tiles made of plain HTML can be picked in the Edit mode**: a click on a `<div>` (a card, a tile, a wrapper) selects it, the breadcrumb shows it, and it can be moved, duplicated, deleted or copied as uu5String.
- **Props taken from the items of a list**: an icon or a text written as `icon={m.icon}` inside `MODULES.map((m) => …)` shows its real value in the Edit panel (for an icon the icon itself and the catalog) and a change is written into **the item of the list** it comes from; the other items keep theirs.
- **uu5String warns about icons a document may not show**: documents can load an older Material Design Icons font than the screens, so newer icons (`mdi-strategy`, `mdi-rocket-launch-outline`, …) stay empty there. **Details** after copying names them, so you can pick older ones.

If you run 0.3.0 or newer, **Download** in the update strip installs this version and restarts the app by itself.

### Requirements
- Claude Code (the app offers to install it) and a Claude account, **or** Codex (the Codex CLI or the ChatGPT app) signed in.
- The plugins come from the uuCodebase marketplace over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.

### Downloads
- `uu5Mock-Studio-0.8.1-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.8.1-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.
