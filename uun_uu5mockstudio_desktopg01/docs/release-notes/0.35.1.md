## uu5Mock Studio 0.35.1

### Changed
- **A screen made from an existing component uses the library components of its code, for real.** Plus4U5Elements.ContentContainer stays a ContentContainer, a StateBadge is not drawn as a Badge – the Plus4U libraries work in the screens of the app. A plan's component tree follows them too, and so does a new component modelled on an existing one. Only the Plus4U application shell and libraries the mockup cannot load are simulated under the real name.
- **The exceptions are shown.** After the agent changes such a screen, the chat shows where it differs from the code: simulated components, components drawn with an equivalent (ContentContainer as Block), library components the code does not use, and for a redesign the ones not drawn. The handoff lists them in HANDOFF.md.
- **The component tree read from the code is more complete**: library components keep their full names (Plus4U5Elements.StateBadge, also when imported by name), and parts kept in variables, in props (`header={…}`, `footer={…}`) and in helper functions of the file are found. Use **Re-read the code** in a project made before this version.

### Requirements
- Claude Code (the app offers to install it) and a Claude account, **or** Codex (the Codex CLI or the ChatGPT app) signed in.
- Picture generation additionally needs an OpenAI API key (optional).
- The plugins come from the uuCodebase marketplaces over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.
- Plus4U documents need the `uubookkit` / `uumanagementkit` plugins (the app installs them), Node.js (`npx`) and a Plus4U sign-in.

### Downloads
- `uu5Mock-Studio-0.35.1-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.35.1-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.
