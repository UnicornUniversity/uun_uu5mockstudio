## uu5Mock Studio 0.3.4

### What's new
- **Plan mode** (the **Agent | Plan** menu next to the model, like in Claude Desktop). In Plan, Claude only prepares a plan and cannot write any file: the file tools are taken away from it. The answer is shown once, as the finished plan.
  - **Questions as cards.** Decisions Claude needs are asked as cards with options (the recommended one first, several answers where it makes sense, your own answer). **Update the plan with my answers** sends them back; **Build** sends them with the plan.
  - **The component tree is a diagram** of boxes, top-down in the order of rendering, with arrows from a component to the one it is nested in (a small circle at the foot for 1:1, none for 1:N). Zoom, move, collapse a subtree, open it large. **Drag a box** onto another one to reorder or nest it (left third = before, right third = after, middle = inside), Esc cancels, Alt + arrows move the selected one. **Edit plan** adds the text and a form for each component. A tree the agent draws as text is turned into the diagram too.
  - **The notation of the Unicorn decomposition** (Jackson Structure Programming): a component rendered once per item (×N), the conditions of rendering (R) and disabling (D), the data it shows (`// label`) and receives, low importance. Claude is told the rules.
  - **Build plan**: with a plan waiting and an empty message, the send button builds it.
- **Structure of a screen** (Screen > Structure… and the context menu): the decomposition of an existing screen, read from its file: sequence, iteration, conditions, components defined in the file opened. A click selects a component; **Show in the inspector** opens it, and the inspector has a way back (**← Structure**). **Plan a change…** starts a plan for that screen. Claude can read the same structure (`screen_structure`) before it plans a change.
- **Rules for all projects**: `GLOBAL_RULES.md` in the folder of the projects, a This project / All projects switch in the Business rules dialog; Claude reads them in every project. Components named in the rules (also `@` suggestions) are described for Claude.
- **New message field**, like in Claude Desktop: one highlighted box with the tools and a round send button inside, the mode and the model as a quiet row below it, also in the Glass Effect.

If you run 0.3.0 or newer, **Download** in the update strip installs this version and restarts the app by itself.

### Requirements
- Claude Code (the app offers to install it) and a Claude account.
- The plugins come from the uuCodebase marketplace over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.

### Downloads
- `uu5Mock-Studio-0.3.4-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.3.4-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.

After that, updates from inside the app (**Check for Updates…** > **Download**) install themselves and need no such step.
