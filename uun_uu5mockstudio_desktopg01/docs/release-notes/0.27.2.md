## uu5Mock Studio 0.27.2

### Fixed
- **Codex respects "no uu5 / uuGDS":** when you say in the chat that a screen must not use uu5 components or uuGDS (for example "bez uu5 a uuGDS", "without uuGDS", "don't use uu5"), the app no longer sends the mandatory skills and no longer sends Codex back to rework the screen into uu5 in its final check. The exception holds for the rest of the conversation.
- **Share of the sitemap sits in the toolbar of the map:** in the full view it is the last button on the right of the row with the search and the fold buttons, so the profile is always the first button from the right in the top bar.
- **No "Claude" while another model works:** the text on the empty canvas and the notice when switching conversations no longer name Claude (it can be Codex).

### Requirements
- Claude Code (the app offers to install it) and a Claude account, **or** Codex (the Codex CLI or the ChatGPT app) signed in.
- Picture generation additionally needs an OpenAI API key (optional).
- The plugins come from the uuCodebase marketplace over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.
- Plus4U documents need the `uubookkit` / `uumanagementkit` plugins of the uuAiMarketplace, Node.js (`npx`) and a Plus4U sign-in.

### Downloads
- `uu5Mock-Studio-0.27.2-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.27.2-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.
