## uu5Mock Studio 0.5.2

### What's new
- **Eco mode** (the leaf under the message box): the agent thinks less, makes the smallest change that does what you ask and answers briefly, so a request is cheaper and faster. Hover over **Eco** for a short explanation of when to turn it on (quick tweaks) and off (a new screen, a bigger redesign). It is styled like **Agent** and the model picker and sits in the middle of the row.
- **Context size under each answer** and a bar suggesting a **new conversation** when the current one has grown large. The token counters of a resumed conversation are cumulative, and a request shows the difference to the previous result.
- **Small JPEG screenshots** are sent to the agent, which saves tokens.
- **Plan card**: quiet buttons on the left, **Discard** and the filled **Build this** on the right, the answers button on its own row.

If you run 0.3.0 or newer, **Download** in the update strip installs this version and restarts the app by itself.

### Requirements
- Claude Code (the app offers to install it) and a Claude account.
- The plugins come from the uuCodebase marketplace over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.

### Downloads
- `uu5Mock-Studio-0.5.2-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.5.2-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.

After that, updates from inside the app (**Check for Updates…** > **Download**) install themselves and need no such step.
