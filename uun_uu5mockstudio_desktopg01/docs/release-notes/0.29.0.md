## uu5Mock Studio 0.29.0

### New
- **Annotate screens and the sitemap:** switch on **Annotate** (the frame with a pointer next to the crosshair in the chat, on the bar over a screen and on the toolbar of the map, or the **A** key), click a component in a screen or a page in the sitemap and write right there what should change. The place gets an orange number and a chip with your note (and a small picture of the component) appears above the message. Annotate several places, on several screens and in the map (a place can have several notes, each with its own number), then **Send**: Claude receives each place with your note, the source of the component and a picture of it as it looks now. Annotations of the sitemap are answered as a plan with the revised map, which you approve. After sending, the annotations leave the screens and stay listed under your message in the chat.

### Changed
- **The sitemap is reviewed with annotations:** the comments of pages, the notes on the whole map and **Revise with the agent** are replaced by annotations, the same as on the screens; **Note on the whole map…** above the map (or a click on the empty map while annotating) annotates the map as a whole. Comments that a map still has become annotations of your next message (one per comment) when it is opened (and leave the map); unsent notes on a whole map become its annotation.

### Requirements
- Claude Code (the app offers to install it) and a Claude account, **or** Codex (the Codex CLI or the ChatGPT app) signed in.
- Picture generation additionally needs an OpenAI API key (optional).
- The plugins come from the uuCodebase marketplaces over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.
- Plus4U documents need the `uubookkit` / `uumanagementkit` plugins (the app installs them), Node.js (`npx`) and a Plus4U sign-in.

### Downloads
- `uu5Mock-Studio-0.29.0-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.29.0-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.
