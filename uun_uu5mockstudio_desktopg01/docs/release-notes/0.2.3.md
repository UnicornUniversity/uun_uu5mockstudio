## uu5Mock Studio 0.2.3

### Fix
- **The downloaded macOS app opens again.** The 0.2.2 build was signed only partly, so macOS reported "uu5Mock Studio is damaged". The whole app is now signed ad hoc, so it opens like any unsigned app (see below). If you installed 0.2.2, replace it with this version.

Everything else is as in 0.2.2 (no toolbar menu: Offline Use under View, Glass Effect fixes, updates from GitHub, ...).

### Requirements
- Claude Code (the app offers to install it) and a Claude account.
- The plugins come from the uuCodebase marketplace over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.

### Downloads
- `uu5Mock-Studio-0.2.3-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.2.3-arm64.zip` – the same app as a zip.

The builds are **not notarized by Apple**. Drag the app to Applications and open it. If macOS blocks it, open System Settings > Privacy & Security and click **Open Anyway**; if it still says "damaged", run `xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"` in Terminal once.
