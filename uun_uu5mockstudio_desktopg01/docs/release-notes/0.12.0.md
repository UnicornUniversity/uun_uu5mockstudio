## uu5Mock Studio 0.12.0

### Changed
- **Templates**: **Web** has Home page, Landing page, Web page and the new **Product detail** (a whole web page with navigation and footer). **Document** has Portal and News (Article became News; Home page, Landing page, Product detail and Report are gone from it).
- **Solution architect** no longer sees the Web and Document levels on the dashboard.
- **Save as template**: the first field is now the **Category** (where the template appears on the dashboard).

### Fixed
- **Dashboard**: after switching the level of templates or the role, the sentence of the previous template stayed in the message field and the next template did not replace it.

If you run 0.3.0 or newer, **Download** in the update strip installs this version and restarts the app by itself.

### Requirements
- Claude Code (the app offers to install it) and a Claude account, **or** Codex (the Codex CLI or the ChatGPT app) signed in.
- The plugins come from the uuCodebase marketplace over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.
- Plus4U documents need the `uubookkit` / `uumanagementkit` plugins of the uuAiMarketplace, Node.js (`npx`) and a Plus4U sign-in.

### Downloads
- `uu5Mock-Studio-0.12.0-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.12.0-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.
