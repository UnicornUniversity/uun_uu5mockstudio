## uu5Mock Studio 0.3.13

### What's new
- **Business rules are recorded by Claude itself.** Besides the rules you state, it records the rules a screen implements (who may do what, conditions of a change of state, validations, what is shown by role or state) without asking; the ones it worked out itself are marked `(assumed)`. A plan names the rules it implies.
- **Plan mode**: **Build** switches the message field back to Agent.
- **Inspector**
  - `colorScheme` and `significance` of the form buttons (Uu5Forms.SubmitButton, CancelButton) are choices.
  - Lists written as a function (`getActionList`, such as the one of ContentContainer) or as a condition between lists (`cond ? [{ … }] : []`) open in the list editor, and their items can be picked.
  - The cursor is a crosshair over buttons and links too; scrolling over a screen works the same with the inspector on (⌥ moves the canvas).
  - Deleting the link `[#1 …]` of a component from the message removes its chip and its frame on the page.
- **Fullscreen preview**: the chat and the notes start minimized as round bubbles of the same size (chat bottom-left, notes bottom-right, with the number of notes). A click opens them, a drag moves them.
- **Selection bar above a screen**: dragging the image or the HTML file into another app moved into **Share** ("Drag the image / the HTML file into an app"); **Export** can save the whole project as a ZIP.

If you run 0.3.0 or newer, **Download** in the update strip installs this version and restarts the app by itself.

### Requirements
- Claude Code (the app offers to install it) and a Claude account.
- The plugins come from the uuCodebase marketplace over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.

### Downloads
- `uu5Mock-Studio-0.3.13-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.3.13-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.

After that, updates from inside the app (**Check for Updates…** > **Download**) install themselves and need no such step.
