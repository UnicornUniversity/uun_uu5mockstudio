## uu5Mock Studio 0.13.0

### Added
- **Brand guidelines** (**Project → Brand Guidelines…**, ⌥⌘B): give the project the customer's brand manual (PDF, HTML or Markdown; you can also drop it into the chat). The app reads it and fills an editable **design guide** (`DESIGN_GUIDE.md`) with colours, fonts and logo sizes; **Improve with Claude** completes it. Every screen follows the guide, and its colours and fonts are available as CSS variables (`--brand-primary`, `--brand-font-body`, …).
- **View → Arrange Screens**: puts the screens of the canvas in order, a screen with variants as one block.
- **Keep Original**: when the original wins over its variants, select **Original** and click **Keep Original**; the variants go to the trash.

### Changed
- **Use A** (use a variant) now also moves the notes, comments and description of the screen to the new one.
- Every dialog closes the same way: a cross at the right end of the header (Esc and a click on the background work too).

If you run 0.3.0 or newer, **Download** in the update strip installs this version and restarts the app by itself.

### Requirements
- Claude Code (the app offers to install it) and a Claude account, **or** Codex (the Codex CLI or the ChatGPT app) signed in.
- The plugins come from the uuCodebase marketplace over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.
- Plus4U documents need the `uubookkit` / `uumanagementkit` plugins of the uuAiMarketplace, Node.js (`npx`) and a Plus4U sign-in.

### Downloads
- `uu5Mock-Studio-0.13.0-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.13.0-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.
