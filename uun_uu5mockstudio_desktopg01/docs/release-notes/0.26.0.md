## uu5Mock Studio 0.26.0

### Added
- **The inspector shows values, not references.** A prop that takes its value from a constant or a variable (`icon: ICON.edit`, `headerColorScheme={colorScheme}`) is shown by the value it has now, in the control of its type: the icon picker for icons, the drop-down for colour schemes and other choices.
- **A change replaces the reference in this place only.** The constant (`ICON`) and the other places that use it keep their value. For an icon, the chip with the name of the reference (`ICON.edit`) switches to changing the constant itself and says how many places use it.
- **`headerColorScheme`, `footerBorderRadius` …** (any prop that ends with `ColorScheme` or `BorderRadius`) are choices from the palette of the screen, like `colorScheme` and `borderRadius`.

### Changed
- **One floating panel less on the canvas.** The tool rail on the left edge is gone: Select is the default state (Esc), Edit is on the bar over a selected screen (and **I**), and the button for the arrows between linked screens moved into the zoom pill in the bottom right corner (shown with two or more screens).

### Requirements
- Claude Code (the app offers to install it) and a Claude account, **or** Codex (the Codex CLI or the ChatGPT app) signed in.
- Picture generation additionally needs an OpenAI API key (optional).
- The plugins come from the uuCodebase marketplace over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.
- Plus4U documents need the `uubookkit` / `uumanagementkit` plugins of the uuAiMarketplace, Node.js (`npx`) and a Plus4U sign-in.

### Downloads
- `uu5Mock-Studio-0.26.0-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.26.0-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.
