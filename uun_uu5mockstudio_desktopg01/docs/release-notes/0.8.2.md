## uu5Mock Studio 0.8.2

### What's new
- **Material Design Icons in the icon picker**: next to uuGDS and uuBml the catalog offers **Material Design** – the 7 000+ icons the screens load, in categories, searchable by name, alias and category (searching "football" finds `mdi-strategy`). An icon that is already `mdi-*` opens the catalog right there.
- **Icons for documents**: icons newer than Material Design Icons 4 have a dashed frame (documents may load the older font and show them empty); **shown in documents** hides them.
- `mdi-*` icons are drawn in the Edit panel too, not only their names.

If you run 0.3.0 or newer, **Download** in the update strip installs this version and restarts the app by itself.

### Requirements
- Claude Code (the app offers to install it) and a Claude account, **or** Codex (the Codex CLI or the ChatGPT app) signed in.
- The plugins come from the uuCodebase marketplace over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.
- The Material Design catalog is downloaded once (Plus4U CDN, jsdelivr) and kept in the app data.

### Downloads
- `uu5Mock-Studio-0.8.2-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.8.2-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.
