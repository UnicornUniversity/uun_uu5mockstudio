## uu5Mock Studio 0.30.0

### Changed
- **One way to point at a place: Annotate.** The crosshair (Pick components) is gone from the message field; Annotate does both. Click a component or a page and write a note, or press **Enter** with nothing written to only link it in your text as `[#1]` (to write "move [#1] under [#2]"). A link becomes an annotation when you write a note to it later. **⌘ / Ctrl + click** takes just the clicked copy of a component repeated by `.map`. Notes and links share one numbering and one kind of chip, and both are listed under your message in the chat. **Use in chat** of the Edit mode links the marked components the same way.

### Requirements
- Claude Code (the app offers to install it) and a Claude account, **or** Codex (the Codex CLI or the ChatGPT app) signed in.
- Picture generation additionally needs an OpenAI API key (optional).
- The plugins come from the uuCodebase marketplaces over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.
- Plus4U documents need the `uubookkit` / `uumanagementkit` plugins (the app installs them), Node.js (`npx`) and a Plus4U sign-in.

### Downloads
- `uu5Mock-Studio-0.30.0-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.30.0-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.
