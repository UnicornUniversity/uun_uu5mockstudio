### What the app does
Desktop app for AI-driven prototyping of uu5 / uuGDS user interfaces: a live canvas of HTML screens, a chat that builds them with your Claude Code, an inspector for real uu5 components (props, icons from the uuGDS catalog), project memory (linked git repository, business rules, project and screen descriptions, notes), export and share (PNG / HTML / project ZIP), and a first-run setup with plugin updates that are offered, never applied silently.

### Requirements
- Claude Code (the app offers to install it) and a Claude account.
- The plugins come from the uuCodebase marketplace over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.
