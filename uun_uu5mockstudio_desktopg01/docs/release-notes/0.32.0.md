## uu5Mock Studio 0.32.0

### Added
- **One page at several places of the sitemap.** A sheet, a regulation or an external document that belongs under several portals is kept **once** and shown at the other places as a **link**: right-click it and choose **Also show under…**, or drag it with **⌥ (Alt)** held. A link is dashed with **↪**, the original shows **×N** (the number of places). It is the same page: its name, type, screen, note and approval are the original's, so a rename shows at every place, and it is counted once. The panel of a link has **Go to the original** (the folded branches open and the map scrolls to it), **Make it a page of its own** and **Remove the link**; the panel of the original lists its other places under **Also shown**. Deleting the original asks first and removes its links too. Links do not count to the 200 pages a map can have.
- **The agent sets the links itself.** Ask it in the chat, e.g. *"where the same regulation is linked from several portals, make it a link; the primary place is the portal of internal regulations"*: it reads the map with the ids of its pages, turns the copies into links and moves a page that is only at a secondary place to its primary place, leaving a link behind. Approved pages are not changed. The map changes at once and the previous one is kept, so the change can be taken back. Planning mode does not change the map.
- **Link a page of the sitemap in your text.** In the Annotate mode, a click on a page of the sitemap and **Enter** with nothing written puts only a link `[#1]` into the message, as for components of a screen. Several selected pages get a link each.

### Fixed
- **Showing a page of the map no longer uncovers the canvas.** Going to a page (a click on an annotation, a search hit, Go to the original) scrolls only the map; in a narrower window it used to shift the whole view aside and the canvas showed through.

### Requirements
- Claude Code (the app offers to install it) and a Claude account, **or** Codex (the Codex CLI or the ChatGPT app) signed in.
- Picture generation additionally needs an OpenAI API key (optional).
- The plugins come from the uuCodebase marketplaces over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.
- Plus4U documents need the `uubookkit` / `uumanagementkit` plugins (the app installs them), Node.js (`npx`) and a Plus4U sign-in.

### Downloads
- `uu5Mock-Studio-0.32.0-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.32.0-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.
