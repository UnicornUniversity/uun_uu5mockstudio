## uu5Mock Studio 0.37.0

### New
- **The user guide in the app**: **Help → User Guide…** (⇧⌘/). On the left are the chapters with their sections and a search field. A search lists the sections that contain all the words, best first, each with a piece of its text; the section opens with the words marked. Links between chapters open in the same window and **←** goes back.
- **The guide in the search field of the Help menu** (macOS): type a few words and the sections of the guide are listed as Help Topics under the menu items. Pick one and the guide opens at that section; **Show All Help Topics** opens the guide with those words in its search.
- **The user guide describes the latest features**: start from an existing component, screens of several components, Update from code, the handoff with Codex and the tools found on this computer, the shorter screen menu and descriptions edited in place.

### Fixed
- A link between two chapters of the user guide led to a section that does not exist.

### Requirements
- Claude Code (the app offers to install it) and a Claude account, **or** Codex (the Codex CLI or the ChatGPT app) signed in.
- Picture generation additionally needs an OpenAI API key (optional).
- The plugins come from the uuCodebase marketplaces over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.
- Plus4U documents need the `uubookkit` / `uumanagementkit` plugins (the app installs them), Node.js (`npx`) and a Plus4U sign-in.

### Downloads
- `uu5Mock-Studio-0.37.0-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.37.0-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.
