## uu5Mock Studio 0.20.0

### New
- **One page or the whole site.** For **Web** and **Document** the dashboard has a second choice: **One page**, or **Whole web site** / **Portal (several pages)**. A whole site starts with a plan, also in the Simple view: the agent proposes the sitemap first, you approve it, then the pages are built.

### Changed
- **The sitemap is offered only where it makes sense.** The **Sitemap** button of the toolbar and **Add a sitemap** on a plan card are shown in a project started as a whole web site or portal, and in any project that already has a sitemap. A project of an application, a route, a component or one page no longer shows them. Web and Document projects made before this version keep the button.
- **A sitemap can still be made anywhere:** the **Plans** menu ends with **Add a sitemap** (**From the screens**, **Empty map**, **Ask the agent…**). Once the project has a sitemap, the button is in the toolbar.
- **The agent proposes a sitemap only for a web site or portal.** In a project of an application, a route, a component or one page it plans no sitemap unless you ask for one.
- In the Simple view the message field goes back to building after **Approve the map**.

### Requirements
- Claude Code (the app offers to install it) and a Claude account, **or** Codex (the Codex CLI or the ChatGPT app) signed in.
- The plugins come from the uuCodebase marketplace over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.
- Plus4U documents need the `uubookkit` / `uumanagementkit` plugins of the uuAiMarketplace, Node.js (`npx`) and a Plus4U sign-in.

### Downloads
- `uu5Mock-Studio-0.20.0-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.20.0-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.
