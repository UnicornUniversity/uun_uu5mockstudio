## uu5Mock Studio 0.10.2

### New
- **A preview of any link**: paste any http(s) link into the message field (or on the dashboard) and it gets a card like a Plus4U document does. The app opens the page itself, keeps its text and a picture of the whole page in the project, and shows them in the card; the agent reads both when you send. Click the card for the large picture, **Load with my access…** opens the page in a window where you sign in and show it the way it should look, **Open in browser** opens it in your browser. A link that cannot be opened (no such address, error page) shows the reason and does not stop the message: the link stays in the text.
- **Pictures for the design**: an attached image can be switched from *Reference* to *In design* (a label on its thumbnail). The app saves it in the project's `assets` folder and the agent places it into the screen as it is (logo, a specific picture) instead of only looking at it. The ZIP export includes the pictures. An SVG (a logo) works too, as long as it is a plain drawing without script.
- **UuWebKit.Bricks in the catalogue**: the Bricks of web sites (carousel, emphasized section, info tiles, navigation, footer …, 43 components of `uu5-webkitg02`) are offered with their props and a live preview.

If you run 0.3.0 or newer, **Download** in the update strip installs this version and restarts the app by itself.

### Requirements
- Claude Code (the app offers to install it) and a Claude account, **or** Codex (the Codex CLI or the ChatGPT app) signed in.
- The plugins come from the uuCodebase marketplace over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.
- Plus4U documents need the `uubookkit` / `uumanagementkit` plugins of the uuAiMarketplace, Node.js (`npx`) and a Plus4U sign-in.

### Downloads
- `uu5Mock-Studio-0.10.2-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.10.2-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.
