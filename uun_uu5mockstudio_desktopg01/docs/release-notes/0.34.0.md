## uu5Mock Studio 0.34.0

### Changed
- **Choosing the content area of a frame is easier.** When you point at the content of a page, the highlight starts at the whole content area (★ in the label at the top), without the top bar, the menu, the breadcrumbs and the title of the page, e.g. the part of a uuManagementKit document where its components are. Each turn of the wheel (or ▲ ▼) really makes the area larger or smaller, because wrappers of the same size are skipped, and the label shows the level. A size you set with the wheel stays while the pointer is inside it; an area highlighted only on the way no longer holds the pointer when it comes back to the content.
- **Annotations on the sitemap change it at once.** In Agent mode, notes on pages of the project's sitemap are carried out right away (the previous map is kept, so the change can be taken back); a note that is a question gets an answer. In Plan mode, and on the map of a plan, annotations are still answered with a revised plan.
- **The hint in the message field follows the view**: it asks what should change in the sitemap or in the plan you are looking at.

### Requirements
- Claude Code (the app offers to install it) and a Claude account, **or** Codex (the Codex CLI or the ChatGPT app) signed in.
- Picture generation additionally needs an OpenAI API key (optional).
- The plugins come from the uuCodebase marketplaces over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.
- Plus4U documents need the `uubookkit` / `uumanagementkit` plugins (the app installs them), Node.js (`npx`) and a Plus4U sign-in.

### Downloads
- `uu5Mock-Studio-0.34.0-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.34.0-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.
