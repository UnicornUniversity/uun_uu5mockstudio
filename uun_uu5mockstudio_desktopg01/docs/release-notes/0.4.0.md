## uu5Mock Studio 0.4.0

### What's new
- **Dashboard**: the app starts on a dashboard.
  - Write what you want to design (**Agent** or **Plan**, model of your choice, idea chips for a quick start): a project is created, the chat goes on there, and the project is named after the first screen the agent makes.
  - Your projects are cards (or a list) with a picture of **the whole canvas**; **Recents** / **All projects**, search, a bin on hover deletes a project (it goes to the system trash).
  - The projects folder: **Reveal** and **Change…**. **File → Dashboard (⇧⌘D)** brings you back.
- **Present** replaces the fullscreen preview: one screen alone over the whole window (no chat, notes or bars), a small button in the corner to stop (**Esc** or ⌘Enter too) and a choice of the device size. Start it with **⌘Enter**.
- **Side panel with tabs**: **Agent** (chat, Agent / Plan switch) and **Components** (browser of the library components; **Add to message** puts `@Name` into the message).
- **Quieter bars**: one zoom pill on top (the inspector and project description are icons there), a short icon bar over the selected screen, the description line only when a description exists. **View → Device for All Screens** sets the size of all screens.
- **Documentation**: a user guide and technical documentation in `docs/` (English).
- Dialogs for the project description and the rules close with **Esc** (an unsaved edit is taken back first).

If you run 0.3.0 or newer, **Download** in the update strip installs this version and restarts the app by itself.

### Requirements
- Claude Code (the app offers to install it) and a Claude account.
- The plugins come from the uuCodebase marketplace over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.

### Downloads
- `uu5Mock-Studio-0.4.0-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.4.0-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.

After that, updates from inside the app (**Check for Updates…** > **Download**) install themselves and need no such step.
