## uu5Mock Studio 0.5.0

### What's new
- **Templates** for new projects, on three levels after the uu5 vocabulary: **Application** (uu5Uve: a shell with local navigation and several routes), **Route** (uu5Route) and **Component** (form, list, detail, dashboard).
  - On the dashboard choose the level and a template (a badge in the message field shows it); the project starts from the template's files and the agent changes them according to your request instead of starting from scratch.
  - **Application and Route templates make the agent design a real route header**: a title naming the subject of the page and the actions of that route (main actions first, overflow collapsed), the same simulated Top and navigation on every route. An application project is named after the application.
  - **Templates…** (dashboard, File menu) shows where they come from: built into the app, brought by installed plugins (a plugin can ship a `templates/` folder) and your own folder. How to write a template: `docs/dev/13-templates.md`.
- Also since 0.4.0: update notices are visible on the dashboard, and the project pictures on the dashboard wait until the screens have rendered.

If you run 0.3.0 or newer, **Download** in the update strip installs this version and restarts the app by itself.

### Requirements
- Claude Code (the app offers to install it) and a Claude account.
- The plugins come from the uuCodebase marketplace over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.

### Downloads
- `uu5Mock-Studio-0.5.0-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.5.0-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.

After that, updates from inside the app (**Check for Updates…** > **Download**) install themselves and need no such step.
