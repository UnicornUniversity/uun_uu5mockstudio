## uu5Mock Studio 0.3.1

### What's new
- **Mention in chat addresses the marked component.** With components marked in the inspector, right click > **Mention component in chat** (or **Mention N components in chat**) adds them to the message as chips. **Mention screen in chat** mentions the screen itself. Screen > Mention in Chat in the menu does the same.

Everything else is as in 0.3.0 (the app updates itself on macOS, Show / Hide inspector in the screen menu, Glass Effect menu fixes, ...). If you run 0.3.0, the **Download** button in the update strip installs this version and restarts the app by itself.

### Requirements
- Claude Code (the app offers to install it) and a Claude account.
- The plugins come from the uuCodebase marketplace over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.

### Downloads
- `uu5Mock-Studio-0.3.1-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.3.1-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.

After that, updates from inside the app (**Check for Updates…** > **Download**) install themselves and need no such step.
