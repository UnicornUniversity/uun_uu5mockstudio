## uu5Mock Studio 0.36.0

### New
- **Update from code** (right-click a screen › Code, or the Project menu): the component is read again from the repository and compared with the reading the screen was made from. The agent brings only what changed in the code into the screen and keeps everything you changed on it; where the code and your change meet in the same place, your version stays and the agent lists it as a conflict. The update is one step of Undo.
- **Screens of several existing components in one project**: each screen follows the component it was made from. The Project menu lists every component with its screens; the component tree, Re-read the code, the exceptions after the agent's changes and the handoff all use the screen's own component.
- **Codex in the steps after a handoff**: a Codex tab next to VS Code, the Claude app and Terminal. Only the tools found on this computer are offered (the Claude and Codex apps, their command-line tools, VS Code with the Claude Code or Codex extension).
- **The description under a screen is edited in place**: click it, type, Enter saves, Esc takes it back.
- **ArtifactLink and the other components of uu_tg01-elements** (`UuTElements`) load for real in a mockup, so a screen made from a component that uses them looks like the original.
- The welcome tour shows the new card **From your code and back**.

### Changed
- **The screen menu is shorter**: the everyday actions stay at the top, the rest is in the Screen, Code and File submenus.
- **Description…** of a screen shows only that screen's description; the whole project's descriptions open from the project.
- The handoff dialog has one scroll area.
- Reading a component follows JSX passed through a split of props and spread into a component (`{...containerProps}` with `title: <Header/>`).

### Fixed
- **Handing off a screen compared it with the wrong component** when the project had screens of several components: everything came out as Keep. It is now compared with the screen's own component.
- Switching to another project left the Edit panel of a component picked in the previous one open.
- A sentence the agent wrote under a screen's heading in the business rules of a new project could turn into that screen's description.

### Requirements
- Claude Code (the app offers to install it) and a Claude account, **or** Codex (the Codex CLI or the ChatGPT app) signed in.
- Picture generation additionally needs an OpenAI API key (optional).
- The plugins come from the uuCodebase marketplaces over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.
- Plus4U documents need the `uubookkit` / `uumanagementkit` plugins (the app installs them), Node.js (`npx`) and a Plus4U sign-in.

### Downloads
- `uu5Mock-Studio-0.36.0-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.36.0-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.
