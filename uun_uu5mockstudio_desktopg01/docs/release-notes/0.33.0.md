## uu5Mock Studio 0.33.0

### New
- **The agent changes the sitemap.** Ask it to add pages or groups, rename them, move pages into another group or remove them, e.g. "put Company offers, Contracts and Practice evaluation under a new group Professional practice". The agent does it in one step (the new tool `sitemap_edit`), the map changes at once and **the previous map is kept**, so the change can be taken back on the sitemap. Pages you have approved are never renamed, moved or removed, and removing a page never deletes its screen. While planning, the plan describes the changes of the map and they are made when the plan is built.

### Changed
- **Building a plan shows the canvas.** After **Approve & build** the app goes back to the canvas, where the screens appear as they are built (the sitemap and the plan are a click away).
- **Fit the map fills the view.** A small or folded sitemap is now enlarged too (up to 200 %), not only a big one made smaller, and the fitted map sits in the middle of the free space.
- **Make a sitemap from this plan** is offered only on a plan that is still a proposal, and not while the agent is working.
- **Real links** on the sitemap shows only when the screens have links the map does not show, or screens that are not in the map.

### Fixed
- After a plan was approved, the view could stay on an empty page instead of the plan or the canvas.
- When macOS keeps the projects folder closed to the app, the app starts with an empty list of projects and says why, instead of failing to start.

### Requirements
- Claude Code (the app offers to install it) and a Claude account, **or** Codex (the Codex CLI or the ChatGPT app) signed in.
- Picture generation additionally needs an OpenAI API key (optional).
- The plugins come from the uuCodebase marketplaces over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.
- Plus4U documents need the `uubookkit` / `uumanagementkit` plugins (the app installs them), Node.js (`npx`) and a Plus4U sign-in.

### Downloads
- `uu5Mock-Studio-0.33.0-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.33.0-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.
