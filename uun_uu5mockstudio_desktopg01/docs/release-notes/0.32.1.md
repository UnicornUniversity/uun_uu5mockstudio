## uu5Mock Studio 0.32.1

### Fixed
- **The app shows its window after an update.** macOS may not let a newly installed version into the **Documents** folder (where the projects are) until you allow it again; the app then started without any window. Now the window opens and a message says what to do: **Open System Settings** goes to Privacy & Security → Files and Folders, where you allow uu5Mock Studio the Documents Folder (or give it Full Disk Access), then open the app again; **Choose Another Folder…** picks another folder for the projects. Any other failed start shows an error instead of an invisible app.

### Changed
- **One Plus4U sign-in for the app and the documents.** The Plus4U sign-in that reads pasted documents (uuBookKit, uuManagementKit) used to open in the system browser, apart from the app's own sign-in. Now it opens in the app's sign-in window, so signing in once serves both, and while the app is signed in the documents are read without asking again.

### Requirements
- Claude Code (the app offers to install it) and a Claude account, **or** Codex (the Codex CLI or the ChatGPT app) signed in.
- Picture generation additionally needs an OpenAI API key (optional).
- The plugins come from the uuCodebase marketplaces over SSH (access to uuCodebase required), or point `prerequisites.json` / `STUDIO_MARKETPLACE_SOURCE` at another source.
- Plus4U documents need the `uubookkit` / `uumanagementkit` plugins (the app installs them), Node.js (`npx`) and a Plus4U sign-in.

### Downloads
- `uu5Mock-Studio-0.32.1-arm64.dmg` – macOS (Apple Silicon).
- `uu5Mock-Studio-0.32.1-arm64.zip` – the same app as a zip (the update downloads this one).

The builds are **not notarized by Apple**, so macOS blocks a downloaded copy. Install it like this, once:

1. Open the `.dmg` and drag **uu5Mock Studio** to **Applications**.
2. Open **Terminal** and run:

       xattr -dr com.apple.quarantine "/Applications/uu5Mock Studio.app"

3. Open the app from Applications.
